### ponytail 说明

- `plugins/ponytail` 取自定义工作区内的完整插件仓库（已排除 `.git`），含 6 个 skills、6 个命令（ponytail-audit / debt / gain / help / review / ponytail）、hooks 及多 CLI 适配目录（Claude / Cursor / Codex / Windsurf / OpenCode 等），可作为独立插件仓库使用。
- 原始插件缓存中另有一份精简版 ponytail（仅 1 个 skill），系过期子集，未打包。
- 激活方式：按仓库内 README/AGENTS.md 的说明接入；激活后会在 `~/.qoder/` 下生成 `.ponytail-active` 标记。

### 注册状态快照说明

- `config/settings.json` 的 `enabledPlugins` 段记录了启用状态（better-harness、qoder-create-plugin、mobile-frontend-dev 为 true；security-scan 为 false）。
- `config/installed_plugins*.json` 为注册表快照，当时存在新旧两套格式且内容不一致，以新版 `installed_plugins_v2.json` 为准。
- `config/external-commands-registry.json` 为外部命令 wiki（v0.0.18）的注册记录。

## 四、恢复到新机器

1. 安装并登录 Qoder。
2. 复制 `skills/*` → `%USERPROFILE%\.qoder\skills\`。
3. 复制 `rules/*` → `%USERPROFILE%\.qoder\rules\`。
4. 恢复插件（二选一或混用）：
   - 市场插件（better-harness、qoder-create-plugin、security-scan）：在 Qoder 插件市场搜索同名安装，版本以快照为准。
   - 本地插件（mobile-frontend-dev、refactoring、ponytail）：在 Qoder 中以本地插件方式指向本包 `plugins/` 下对应目录。
5. 参照 `config/settings.json` 设置 `enabledPlugins` 启用状态；用 `config/installed_plugins*.json` 核对版本。
6. 重启 Qoder，检查 skills 列表包含上述 6 个用户级 skills 与各插件 skills。

## 注意事项

- 本包为**当时状态的快照**，源机器之后的修改不会自动同步。
- 内置 skills 由客户端提供，不落盘、不打包。
- `.ponytail-active` 等会话状态标记未打包（重新激活即可）。
- 恢复后如插件版本与快照不一致，以市场最新版为准，通常向前兼容。
