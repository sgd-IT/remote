# project-map 模板与参考

## AGENTS.md 模板（<40 行）

```markdown
# AGENTS.md — <仓库名>

> 最后核实：YYYY-MM-DD

## 硬约束（改代码前必读）
1. <禁令 1：如"不得新建数据库连接，必须复用现有连接池">
2. <禁令 2：如"跨端契约变更必须同步更新 docs/<契约文档>">
3. <禁令 3>

## 常用命令
- 启动：<命令>
- 测试：<命令>
- 构建：<命令>

## 文档索引（比本文件更细）
- 架构与契约：<相对路径>
- 改哪里速查：docs/INDEX.md
- 决策记录：docs/adr/

## 更新触发器
- 端口/启动方式变化、文档增删、约束变更时，必须同步本文件。
```

写作要点：禁令必须是"可执行的规则"（能判断是否违规），不是口号；命令必须可直接复制运行；索引一律用相对路径。

## docs/INDEX.md 模板

```markdown
# <项目名> 速查索引

> 最后核实：YYYY-MM-DD

## 业务域 × 端

| 业务域 | 后端入口 | 前端页面 | API 文件 | 其他端 |
|---|---|---|---|---|

## 我要做 X → 改哪里

| 任务 | 改这里 | 注意 |
|---|---|---|

## 已知坑

- <现象 + 规避方式>

## 更新触发器

- 新增业务域、入口文件增删、目录结构调整时更新；每季度抽查路径有效性。
```

## ADR 模板（追溯性）

```markdown
# ADR-NNN：<决策标题>

- 状态：追溯记录（补充于 YYYY-MM-DD）

## 背景
<什么场景/约束逼出了这个设计>

## 决策
<选了什么>

## 备选方案与拒绝原因
<为什么没选另一个方案>

## 适用边界
<什么前提下有效；什么条件出现时应重新评估>

## 代码位置
<关键文件路径>
```

挑选标准：代码里"看起来奇怪但显然是有意为之"的地方——多套并存实现、兜底 hack、反直觉约定。

## 对话版地图骨架

```text
【<工作区名>·project-map】

一、系统全景图（ASCII ≤15 行，标注端口与协议）
二、各仓/模块结构（每仓：技术栈 / 模块职责表 / 请求链路 / 配置位置）
三、业务域 × 端 速查表
四、我要做 X → 改哪里
五、既有文档索引（按"先读哪个"排序）
六、已知坑（漂移 / 易混 / 巨型文件 / 契约暗号）
```

## 常见技术栈盘点命令（只读）

| 栈 | 盘点位置/命令 |
|---|---|
| Node / 前端 | package.json（scripts、deps）、src 目录、.env*、vite/webpack 配置、路由注册文件 |
| Java / Maven | pom.xml（modules）、@SpringBootApplication 启动类、application*.yaml；`mvn dependency:tree` |
| Python | pyproject.toml / requirements.txt、入口 main.py、settings 文件 |
| Go | go.mod、cmd/ 目录 |
| 通用 | `**/README*.md`、`**/*.md`、docs/、`git -C <repo> log --oneline -20` |

Git 边界：上表命令均只读；禁止 add / commit / push / stash / reset / checkout。
