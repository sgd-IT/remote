### 消防远程值守平台（2026.04 - 至今）

**一句话**：面向多租户的消防物联网值守平台，接入 GB/T 26875 国标与大华私有协议设备，覆盖 PC 大屏、管理后台与移动端。

**技术栈**：Java / Spring Boot / MyBatis-Plus / MySQL / Redis / Netty-Vert.x / MQTT / Vue3 / ECharts / UniApp / Nginx / Docker

**职责与成果**：

1. 负责告警中心后端链路：统一 TCP、UDP、AEP、摄像头四类告警入口，设计统一消息模型 + 来源枚举 + 策略工厂，新增告警来源只需扩展枚举与策略实现，不改主流程（6 个文件 809 行）。
2. 负责告警去重与工单状态口径：基于 ConcurrentHashMap 原子占位 + CAS 刷新实现 5 分钟窗口去重，修复窗口边界竞态；抽象三级状态解析器（权威字段 > 兼容文本 > 兜底），Java 与 SQL 同源，解决列表筛选与统计数字不一致。
3. 负责大华协议接入：按 GB/T 26875 实现 TCP/UDP 帧解析、确认帧构建与 0x84 模拟量解析，抽取公共解析模块，两个组件删除重复代码 2,782 行。
4. 负责设备在线状态判定：统一按产品 keep_alive_time（上报周期 × 2）计算离线，删除组件内内存会话表与周期清理，消除大华终端 1 小时上报被误判离线的问题。
5. 参与告警语义迁移：31,563 条存量告警按事件名称逐项映射，采用"行级判据 + 读侧先于写侧原子切换"方案，支持全程回退；后端 542 文件 clean 编译通过。
6. 负责数据中心与报表：统计接口参数化近 N 天窗口，前端五个分析组件改 ECharts；PDF 月/季/年同模板导出，字体随包解决线上容器依赖。
7. 负责移动端从 0 到 1：UniApp 完成登录、值班、告警、统计等页面，封装请求层（token 刷新 + 401 自动重放），接入真实接口替换 mock。

### 3.2 高频追问（按主题）

| 主题 | 面试官可能问 | 答题要点 |
|---|---|---|
| 并发 | 你的去重怎么做的？为什么用 ConcurrentHashMap？ | putIfAbsent 原子占位避免 get-then-put 竞态；非重复才 CAS 刷新时间戳；CAS 失败应视为重复；强一致要靠唯一索引，内存缓存只是第一层 |
| 并发 | CAS 是什么？ABA 问题了解吗？ | 比较并交换，依赖 CPU 原子指令；ConcurrentHashMap 用版本戳规避 ABA；业务里 CAS 失败就重试或放弃 |
| 并发 | 定时任务和业务写入冲突怎么办？ | 先定幂等键，任务侧跳过已存在数据；批量查已存在集合替代循环查库；必要时加分布式锁 |
| 协议 | TCP 粘包/拆包怎么处理？ | 定长头 + 长度字段；按长度字段循环切帧；异常时复位状态机，避免错位后持续吞帧 |
| 协议 | 字节序踩过什么坑？ | 下行地址大小端、长度字段字节序各踩过一次；用 Wireshark/日志 hex 对照协议文档逐字段核对 |
| 协议 | 设备离线怎么判定？为什么不用固定 60 秒？ | 大华终端 1 小时一报，固定秒级超时会误判；阈值 = 上报周期 × 2；在线状态只留一个判定源 |
| 协议 | MQTT QoS 区别？ | 0 最多一次、1 至少一次、2 恰好一次；信令类用 QoS1，删除类用 QoS0，retained 防过期指令重放 |
| 数据库 | 31,563 条数据怎么迁移的？ | 先加列留痕（全 NULL 校验）；按事件名称逐项映射而非类型字段；读侧双读、写侧单一判据；读先于写可回退 |
| 数据库 | SQL 慢怎么排查？ | explain 看 type/key/rows；复合索引最左前缀；避免函数包裹索引列；分页深翻用游标 |
| 数据库 | Java 和 SQL 两套状态口径怎么保证一致？ | SQL CASE 片段做成常量放在解析器里；改一处两边生效；上线前用同一批数据对账 |
| 多租户 | 租户隔离怎么做的？ | 登录上下文 + DAO 拦截器自动加租户条件 + WebSocket 会话过滤，三层一致；跨租户查询只对超管开放 |
| 权限 | 权限模型？ | RBAC，菜单/按钮权限码；数据权限用规则链扩展区域维度 |
| 前端 | 视频流方案怎么选的？ | flv.js → dhflv（H.265）→ dhhls（多流）→ WSPlayer；按浏览器兼容与编码格式降级，反代要支持 WebSocket |
| 前端 | 大数据量图表怎么优化？ | 按需渲染、KeepAlive 缓存、避免重复初始化实例、容器尺寸变化时 resize |
| 移动端 | token 过期怎么处理？ | 401 拦截 → 单例刷新队列（防并发风暴）→ 重放原请求；刷新失败跳登录 |
| 项目 | 你最大的难点？ | 二选一：告警去重竞态（并发）或设备离线误判（领域理解），讲"现象 → 定位 → 根因 → 方案 → 验证" |
