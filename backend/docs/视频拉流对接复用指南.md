# 视频拉流对接复用指南（大华 ICC + WSPlayer）

> 本文档整理自「安为智慧消防远程值守系统」的视频拉流实现，供其他系统复用参考。
> 整体方案：**前端大华 WSPlayer 插件 + 本项目后端转发 ICC 开放接口 + 大华 ICC 平台（DSS/流媒体）**，支持实时预览（RTSP/FLV/HLS 三协议）与语音对讲。

---

## 一、整体架构

```
┌─────────────┐   1.请求流地址    ┌──────────────────┐   2.转发ICC接口   ┌────────────────────┐
│  前端浏览器  │ ────────────────▶ │  本项目后端       │ ───────────────▶ │  大华 ICC 平台      │
│  (WSPlayer) │                   │  (Spring Boot)   │                  │  evo-apigw 网关     │
│             │ ◀──────────────── │  VideoCameraCtrl │ ◀─────────────── │  https://IP:1443    │
└──────┬──────┘  3.返回rtsp+token  └──────────────────┘  4.返回url+token  └────────────────────┘
       │
       │ 5.WSPlayer 连接流媒体服务拉流（ws/wss）
       ▼
┌──────────────────┐
│ 大华流媒体服务     │
│ ws://IP:9100      │
│ wss://IP:9102     │
│ flv  http://IP:7886 │
└──────────────────┘
```

**核心设计原则**：
1. **ICC 接口全部由后端转发**——前端不直连 ICC，避免暴露 ICC 账号密码/密钥，也便于统一管控租户权限。
2. **前端只拿"流地址 + 一次性 token"**——播放器（WSPlayer）内部自动完成真正的拉流。
3. **WS 连接地址由前端按页面协议自适应**——http 页面直连 `ws://流媒体IP:9100`；https 页面走 nginx 同源反向代理 `wss://本站域名/wsplayer-proxy`（解决混合内容拦截）。

## 二、拉流 IP / 端口清单

### 2.1 当前生产环境实际配置

| 用途 | 地址 | 说明 |
|---|---|---|
| ICC 平台 API 网关 | `https://**:1443` | 存于数据库 `icc_media_server.base_url` |
| ICC 登录用户名 | `system` | 同上，密码 RSA 加密传输 |
| FLV 拉流 | `http://**:7886/live/cameraid/{deviceCode}%24{channelSeq}/substream/{streamType}.flv?token=xxx` | host 从 base_url 提取，端口固定 7886 |
| RTSP 拉流 | ICC StartVideo 接口返回，形如 `rtsp://**:9100/dss/monitor/param/cameraid=xxx` | 由 ICC 返回，不可写死 |
| WSPlayer WebSocket（http 页面） | `ws://**:9100` | 流媒体服务直连 |
| WSPlayer WebSocket（https 页面） | `wss://{本站域名}/wsplayer-proxy` → nginx 转发到 `**:9100` | 解决混合内容拦截 |

### 2.2 音视频端口速查

| 端口 | 协议 | 用途 |
|---|---|---|
| 1443 | https | ICC 平台 API 网关（evo-apigw） |
| 9100 | ws | WSPlayer 实时拉流（WebSocket 明文） |
| 9102 | wss | WSPlayer 实时拉流（WebSocket TLS，部分环境不可用） |
| 7886 | http | FLV 实时流 |
| 7086 | http | HLS 实时流（m3u8，示例端口，以 ICC 返回为准） |

> ⚠️ 换成新系统复用时：只需改数据库 `icc_media_server.base_url` + nginx `/wsplayer-proxy` 的 proxy_pass 目标 IP。

**4 段式通道编码规则（关键！）**：

### 4.4 ICC 开放接口客户端（核心类）`IccOpenApiClient`

负责：Token 管理（RSA 加密密码登录 + 自动刷新）、StartVideo 取流、HLS 取流、FLV 地址拼接、语音对讲。

```java
@Slf4j
@Component
public class IccOpenApiClient {

    private volatile String accessToken;
    private volatile String refreshToken;
    private volatile String magicId;
    private volatile Instant tokenExpireTime;
    private final Object tokenLock = new Object();

    /** 获取有效 token，失败自动刷新（提前5分钟过期） */
    public String getAccessToken(IccMediaServerDO config) {
        if (isTokenValid()) {
            return accessToken;
        }
        synchronized (tokenLock) {
            if (isTokenValid()) {
                return accessToken;
            }
            refreshToken(config);
            return accessToken;
        }
    }

    private boolean isTokenValid() {
        if (StrUtil.isBlank(accessToken) || tokenExpireTime == null) {
            return false;
        }
        return Instant.now().isBefore(tokenExpireTime.minusSeconds(300));
    }

    /** hutool 会把 JSON null 解析为 JSONNull，统一转 null 避免强转异常 */
    private static String strOrNull(Object v) {
        return (v == null || v instanceof JSONNull) ? null : String.valueOf(v);
    }

    private static Integer intOrNull(Object v) {
        return (v instanceof Number) ? ((Number) v).intValue() : null;
    }

    /** 刷新 Token：RSA 加密密码 + 合作方凭证换 access_token */
    private void refreshToken(IccMediaServerDO config) {
        try {
            String publicKey = getPublicKey(config.getBaseUrl());
            String encryptedPassword = doEncryptPassword(config.getPassword(), publicKey);
            Map<String, Object> body = new HashMap<>();
            body.put("grant_type", "password");
            body.put("username", config.getUsername());
            body.put("password", encryptedPassword);
            body.put("client_id", config.getClientId());
            body.put("client_secret", config.getClientSecret());
            body.put("public_key", publicKey);

            String url = config.getBaseUrl() + "/evo-apigw/evo-oauth/1.0.0/oauth/extend/token";
            HttpResponse response = HttpRequest.post(url)
                    .header("Content-Type", "application/json")
                    .body(JSONUtil.toJsonStr(body))
                    .timeout(10000)
                    .execute();

            Map<String, Object> result = JSONUtil.toBean(response.body(), Map.class);
            if (!Boolean.TRUE.equals(result.get("success"))) {
                throw new RuntimeException("ICC Token获取失败: " + result.getOrDefault("errMsg", "Unknown error"));
            }

            Map<String, Object> data = (Map<String, Object>) result.get("data");
            this.accessToken = strOrNull(data.get("access_token"));
            this.refreshToken = strOrNull(data.get("refresh_token"));
            this.magicId = strOrNull(data.get("magicId"));
            Object expObj = data.get("expires_in");
            Long expiresIn = expObj instanceof Number ? ((Number) expObj).longValue() : 604799L;
            this.tokenExpireTime = Instant.now().plusSeconds(expiresIn);
            log.info("[IccOpenApiClient] Token刷新成功，有效期{}秒", expiresIn);
        } catch (Exception e) {
            log.error("[IccOpenApiClient] Token刷新失败", e);
            throw new RuntimeException("ICC平台连接异常，请联系管理员", e);
        }
    }

    /** 获取 RSA 公钥 */
    public String getPublicKey(String baseUrl) {
        String url = baseUrl + "/evo-apigw/evo-oauth/1.0.0/oauth/public-key";
        HttpResponse response = HttpRequest.get(url).timeout(10000).execute();
        Map<String, Object> result = JSONUtil.toBean(response.body(), Map.class);
        if (!Boolean.TRUE.equals(result.get("success"))) {
            throw new RuntimeException("ICC获取公钥失败: " + result.getOrDefault("errMsg", "Unknown error"));
        }
        Map<String, Object> data = (Map<String, Object>) result.get("data");
        return strOrNull(data.get("publicKey"));
    }

    /** RSA 分段加密密码（单块最大 117 字节） */
    private String doEncryptPassword(String password, String publicKey) throws Exception {
        byte[] decoded = Base64.getDecoder().decode(publicKey);
        RSAPublicKey pubKey = (RSAPublicKey) KeyFactory.getInstance("RSA")
                .generatePublic(new X509EncodedKeySpec(decoded));
        Cipher cipher = Cipher.getInstance("RSA");
        cipher.init(Cipher.ENCRYPT_MODE, pubKey);

        byte[] inputArray = password.getBytes(StandardCharsets.UTF_8);
        int inputLength = inputArray.length;
        int maxEncryptBlock = 117;
        int offSet = 0;
        byte[] resultBytes = {};
        byte[] cache;

        while (inputLength - offSet > 0) {
            if (inputLength - offSet > maxEncryptBlock) {
                cache = cipher.doFinal(inputArray, offSet, maxEncryptBlock);
                offSet += maxEncryptBlock;
            } else {
                cache = cipher.doFinal(inputArray, offSet, inputLength - offSet);
                offSet = inputLength;
            }
            resultBytes = Arrays.copyOf(resultBytes, resultBytes.length + cache.length);
            System.arraycopy(cache, 0, resultBytes, resultBytes.length - cache.length, cache.length);
        }
        return Base64.getEncoder().encodeToString(resultBytes);
    }

    /** WSPlayer 实时预览取流（RTSP + 一次性token），供前端播放器使用 */
    public IccStartVideoRespDTO startVideo(IccMediaServerDO config, String deviceId, String channelId, String streamType) {
        String token = getAccessToken(config);
        String url = config.getBaseUrl() + "/evo-apigw/admin/API/MTS/Video/StartVideo";

        Map<String, Object> data = new HashMap<>();
        data.put("deviceId", deviceId);
        data.put("channelId", channelId);
        data.put("dataType", "1");
        data.put("streamType", streamType != null && !streamType.isEmpty() ? streamType : "2");

        Map<String, Object> body = new HashMap<>();
        body.put("data", data);

        HttpResponse response = HttpRequest.post(url)
                .header("Content-Type", "application/json")
                .header("Authorization", "bearer " + token)
                .body(JSONUtil.toJsonStr(body))
                .timeout(10000)
                .execute();

        Map<String, Object> result = JSONUtil.toBean(response.body(), Map.class);
        Integer code = ((Number) result.get("code")).intValue();
        if (code != 1000) {
            throw new RuntimeException("ICC取流失败: " + result.getOrDefault("desc", "Unknown error"));
        }

        Map<String, Object> respData = (Map<String, Object>) result.get("data");
        IccStartVideoRespDTO dto = new IccStartVideoRespDTO();
        dto.setUrl(strOrNull(respData.get("url")));
        dto.setToken(strOrNull(respData.get("token")));
        dto.setTrackId(strOrNull(respData.get("trackId")));
        dto.setSession(strOrNull(respData.get("session")));
        dto.setInnerIp(strOrNull(respData.get("innerIp")));
        dto.setWssDirect(intOrNull(respData.get("wssDirect")));
        dto.setNetFlag(strOrNull(respData.get("netFlag")));
        return dto;
    }

    /** HLS 取流（回放/兼容场景） */
    public String getRealtimeStreamUrl(IccMediaServerDO config, String channelCode, String streamType, String scheme) {
        String accessToken = getAccessToken(config);
        return getRealtimeStreamUrlLegacy(config, accessToken, channelCode, streamType, scheme);
    }

    /** 旧版实时流接口：POST /evo-apigw/admin/API/video/stream/realtime，返回 URL 需手动拼 token */
    private String getRealtimeStreamUrlLegacy(IccMediaServerDO config, String accessToken,
                                              String channelId, String streamType, String type) {
        String url = config.getBaseUrl() + "/evo-apigw/admin/API/video/stream/realtime";

        Map<String, Object> data = new HashMap<>();
        data.put("channelId", channelId);
        data.put("streamType", streamType);
        data.put("type", type);

        Map<String, Object> body = new HashMap<>();
        body.put("data", data);

        HttpResponse response = HttpRequest.post(url)
                .header("Content-Type", "application/json")
                .header("Authorization", "bearer " + accessToken)
                .body(JSONUtil.toJsonStr(body))
                .timeout(10000)
                .execute();

        String respBody = response.body();
        if (response.getStatus() != 200 || !respBody.trim().startsWith("{")) {
            throw new RuntimeException("ICC 实时流接口不可用 (HTTP " + response.getStatus() + ")");
        }

        Map<String, Object> result = JSONUtil.toBean(respBody, Map.class);
        Integer code = ((Number) result.get("code")).intValue();
        if (code != 1000) {
            throw new RuntimeException("ICC获取实时流地址失败: " + result.getOrDefault("desc", "Unknown error"));
        }

        Map<String, Object> respData = (Map<String, Object>) result.get("data");
        String streamUrl = strOrNull(respData.get("url"));
        if (streamUrl == null) {
            throw new RuntimeException("ICC获取实时流地址失败: url 为空");
        }
        streamUrl = streamUrl + "?token=" + accessToken;
        return streamUrl;
    }

    /** FLV 地址拼接：http://{host}:7886/live/cameraid/{deviceCode}%24{channelSeq}/substream/{streamType}.flv?token=xxx */
    public String buildFlvStreamUrl(IccMediaServerDO config, String channelCode, String streamType) {
        String accessToken = getAccessToken(config);
        try {
            java.net.URI uri = new java.net.URI(config.getBaseUrl());
            String host = uri.getHost();

            String deviceCode = channelCode.substring(0, channelCode.indexOf("$"));
            String channelSeq = channelCode.substring(channelCode.lastIndexOf("$") + 1);
            String encodedDevice = URLEncoder.encode(deviceCode, StandardCharsets.UTF_8);

            return String.format("http://%s:7886/live/cameraid/%s%%24%s/substream/%s.flv?token=%s",
                    host, encodedDevice, channelSeq, streamType, accessToken);
        } catch (Exception e) {
            throw new RuntimeException("FLV 流地址构建失败: " + e.getMessage());
        }
    }

    /** 获取 ICC 设备列表（含子系统/通道信息），用于设备信息获取与摄像头批量录入 */
    public List<Map<String, Object>> getDeviceList(IccMediaServerDO config) {
        String token = getAccessToken(config);
        String url = config.getBaseUrl() + "/evo-apigw/evo-brm/1.2.0/device/subsystem/page";

        Map<String, Object> body = new HashMap<>();
        body.put("pageNum", 1);
        body.put("pageSize", 1000);

        HttpResponse response = HttpRequest.post(url)
                .header("Content-Type", "application/json")
                .header("Authorization", "bearer " + token)
                .body(JSONUtil.toJsonStr(body))
                .timeout(10000)
                .execute();

        String respBody = response.body();
        if (response.getStatus() != 200 || !respBody.trim().startsWith("{")) {
            throw new RuntimeException("ICC设备列表接口不可用 (HTTP " + response.getStatus()
                    + ")，请确认ICC平台地址和API路径正确");
        }

        Map<String, Object> result = JSONUtil.toBean(respBody, Map.class);
        if (!Boolean.TRUE.equals(result.get("success"))) {
            throw new RuntimeException("ICC获取设备列表失败: " + result.getOrDefault("errMsg", "Unknown error"));
        }

        Map<String, Object> respData = (Map<String, Object>) result.get("data");
        if (respData == null) {
            return java.util.Collections.emptyList();
        }
        List<Map<String, Object>> devices = (List<Map<String, Object>>) respData.get("pageData");
        return devices != null ? devices : java.util.Collections.emptyList();
    }
}
```

```java
            @RequestParam(value = "cameraId", required = false) Long cameraId,
            @RequestParam(value = "channelId", required = false) String directChannelId,
            @RequestParam(value = "streamType", required = false) String directStreamType) {
        IccMediaServerDO config = mediaServerService.getCurrentTenantConfig();
        if (config == null) {
            throw new RuntimeException("ICC平台未配置");
        }

        String channelCode;
        String deviceCode;
        String streamType;
        if (directChannelId != null && !directChannelId.isEmpty()) {
            // 直接传入 4 段式通道编码（WSPlayer 内置回调场景）
            channelCode = directChannelId;
            deviceCode = directChannelId.contains("$")
                    ? directChannelId.substring(0, directChannelId.indexOf("$")) : directChannelId;
            streamType = directStreamType != null && !directStreamType.isEmpty() ? directStreamType : "2";
        } else {
            VideoCameraDO camera = videoCameraService.getById(cameraId);
            // 通道编码兼容处理：若 channelId 已是 4 段式则直接使用，否则拼接 deviceId$1$0$channelId
            channelCode = camera.getChannelId() != null && camera.getChannelId().contains("$")
                    ? camera.getChannelId()
                    : camera.getDeviceId() + "$1$0$" + camera.getChannelId();
            deviceCode = camera.getDeviceId();
            streamType = camera.getQuality() != null ? camera.getQuality() : "2";
        }

        IccStartVideoRespDTO resp = iccOpenApiClient.startVideo(config, deviceCode, channelCode, streamType);

        WsPlayerStreamRespVO vo = new WsPlayerStreamRespVO();
        vo.setUrl(resp.getUrl());
        vo.setToken(resp.getToken());
        vo.setSession(resp.getSession());
        vo.setChannelId(channelCode);
        vo.setDeviceCode(deviceCode);
        vo.setStreamType(streamType);
        vo.setInnerIp(resp.getInnerIp());
        vo.setWssDirect(resp.getWssDirect());
        vo.setNetFlag(resp.getNetFlag());
        return CommonResult.success(vo);
    }

    /** ② HLS + FLV 双协议取流（用于无 WSPlayer 插件的轻量场景） */
    @GetMapping("/live/url")
    @Operation(summary = "获取实时视频流地址")
    public CommonResult<VideoLiveUrlRespVO> getLiveUrl(@RequestParam("cameraId") Long cameraId) {
        VideoCameraDO camera = videoCameraService.getById(cameraId);
        if (camera == null) {
            throw new RuntimeException("摄像头不存在");
        }
        IccMediaServerDO config = mediaServerService.getCurrentTenantConfig();
        if (config == null) {
            throw new RuntimeException("ICC平台未配置");
        }
        String iccChannelCode = camera.getDeviceId() + "$1$0$" + camera.getChannelId();
        String streamType = camera.getQuality() != null ? camera.getQuality() : "2";
        String hlsUrl = iccOpenApiClient.getRealtimeStreamUrl(config, iccChannelCode, streamType, "hls");
        String flvUrl = iccOpenApiClient.buildFlvStreamUrl(config, iccChannelCode, streamType);

        VideoLiveUrlRespVO vo = new VideoLiveUrlRespVO();
        vo.setUrl(hlsUrl);
        vo.setFlvUrl(flvUrl);
        return CommonResult.success(vo);
    }

    /** ③ 开始对讲（转发 ICC StartTalk） */
    @PostMapping("/wsplayer/talk/start")
    public CommonResult<IccTalkRespDTO> wsPlayerStartTalk(@RequestBody WsPlayerTalkReqVO reqVO) {
        IccMediaServerDO config = mediaServerService.getCurrentTenantConfig();
        if (config == null) {
            throw new RuntimeException("ICC平台未配置");
        }
        IccTalkRespDTO resp = iccOpenApiClient.startTalk(config, reqVO.getDeviceCode(),
                reqVO.getTalkType() != null ? reqVO.getTalkType() : "1",
                reqVO.getAudioType() != null ? reqVO.getAudioType() : "2");

    }

    /** ④ 停止对讲（转发 ICC StopTalk） */
    @PostMapping("/wsplayer/talk/stop")
    public CommonResult<Boolean> wsPlayerStopTalk(@RequestBody WsPlayerTalkReqVO reqVO) {
        IccMediaServerDO config = mediaServerService.getCurrentTenantConfig();
        if (config == null) {
            throw new RuntimeException("ICC平台未配置");

        if (reqVO.getSession() == null || reqVO.getSession().isEmpty()) {

                reqVO.getTalkType() != null ? reqVO.getTalkType() : "1", reqVO.getSession());
        return CommonResult.success(resp);
    }

    /** ⑤ 获取 ICC 平台设备/通道列表（仅平台租户）——设备信息获取入口 */
    @GetMapping("/icc-devices")
    @Operation(summary = "获取 ICC 平台设备/通道列表（仅平台租户）")

    @PostMapping("/batch-create")
    @Operation(summary = "批量创建摄像头（ICC 自动获取，仅平台租户，可指定归属租户）")
```

**批量创建服务实现**（按 tenantId + deviceId + channelId 查重，已存在则跳过）：

```java
@Override
@Transactional(rollbackFor = Exception.class)
public Map<String, Object> batchCreate(Long tenantId, List<VideoCameraDO> cameras) {
    int successCount = 0;
    int skippedCount = 0;
    for (VideoCameraDO camera : cameras) {
        // 忽略租户上下文跨租户查询，按 tenantId + deviceId + channelId 查重，已存在则跳过
        Long exists = TenantUtils.executeIgnoreWithResult(() -> videoCameraMapper.selectCount(
                new LambdaQueryWrapperX<VideoCameraDO>()
                        .eq(VideoCameraDO::getTenantId, tenantId)
                        .eq(VideoCameraDO::getDeviceId, camera.getDeviceId())
                        .eq(VideoCameraDO::getChannelId, camera.getChannelId())));
        if (exists != null && exists > 0) {
            skippedCount++;
            continue;
        }
        // 手动指定归属租户，忽略租户拦截器自动填充当前租户
        camera.setTenantId(tenantId);
        TenantUtils.executeIgnore(() -> videoCameraMapper.insert(camera));
        successCount++;
    }
    Map<String, Object> result = new HashMap<>();
    result.put("successCount", successCount);
    result.put("skippedCount", skippedCount);
    return result;
}
```

```javascript
// WSPlayer 内部回调约定：resolve 返回 { url, token, session, ... } 结构
import request from '@/config/axios'

const WS_BASE = '/eiot/video/camera/wsplayer'

const API = {
  /** 请求实时视频流地址（WSPlayer 内部回调 getRealRtsp） */
  getRealmonitor(realmonitorParam) {
    const data = realmonitorParam?.data || {}
    const channelList = realmonitorParam?.channelList || []
    // WSPlayer 内置播放模式传入 4 段式通道编码，直接透传给后端
    const channelId = data.channelId || (channelList[0] && channelList[0].id) || null
    if (!channelId) {
      return Promise.reject(new Error('getRealmonitor 缺少 channelId'))
    }
    return request.get({
      url: WS_BASE + '/start-video',
      params: { channelId }
    })
  },

  getTalkRtsp(talkParam) {
    const data = talkParam?.data || {}
    return request.post({
      url: WS_BASE + '/talk/start',

        deviceCode: data.deviceCode,
        talkType: '1',                    // 1-设备对讲 2-通道对讲
        audioType: data.audioType || '2', // 2-G711A 4-G711U
        channelSeq: data.channelSeq
      }
    })
  },

  /** 停止对讲（WSPlayer 内部回调 stopTalk） */

    const data = talkParam?.data || {}
    return request.post({
      url: WS_BASE + '/talk/stop',
      data: {
        deviceCode: data.deviceCode,
        talkType: data.talkType || '1',
        session: data.session
      }
    })
```

### 5.3 播放组件 `WsPlayerWrapper.vue`（核心）

封装了：初始化、遮罩/错误提示、单路播放、批量分屏播放、事件回调处理、https 自适应 WS 地址。

```vue
<template>
  <div class="wsplayer-wrapper">
    <!-- WSPlayer 容器：播放器动态加载后往此 div 内渲染 -->
    <div :id="containerId" class="wsplayer-container"></div>
    <!-- 加载/错误遮罩 -->
    <div v-if="showMask" class="wsplayer-mask" :class="{ 'mask-error': !!errorMsg }">
      <el-icon v-if="!errorMsg" class="is-loading mask-icon"><Loading /></el-icon>
      <span class="mask-text">{{ errorMsg || loadingText }}</span>
      <el-button v-if="errorMsg" size="small" type="primary" @click="retry">重试</el-button>
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref, computed, watch, onMounted, onUnmounted, nextTick } from 'vue'
import { Loading } from '@element-plus/icons-vue'
import { PlayerManager } from '../../../../icc/PlayerManager'

const props = withDefaults(
  defineProps<{
    camera?: any | null   // 单个摄像头（video_camera 记录：deviceId/channelId/quality）
    cameras?: any[] | null // 批量播放列表（依次播放到窗口 0..N-1）
    num?: number          // 初始显示窗口数（默认 4 画面）
    showControl?: boolean // 是否显示底部工具栏
  }>(),
  { camera: null, cameras: null, num: 4, showControl: true }
)

const emit = defineEmits<{ close: [] }>()

let uidSeed = 0
const containerId = `wsplayer_${Date.now().toString(36)}_${(uidSeed++).toString(36)}`

let pm: any = null
let initialized = false
let playing = false
let pendingCamera: any = null
let pendingCameraList: any[] | null = null
let initTimeout: ReturnType<typeof setTimeout> | null = null
/** 内部批量关闭窗口的时间窗口（批量播放前 pm.close() 全关会触发 closeVideo 事件，此期间抑制 close 通知） */
let internalCloseUntil = 0

const loading = ref(true)
const loadingText = ref('播放器加载中...')
const errorMsg = ref<string | null>(null)
const currentWindowIndex = ref(0)

const showMask = computed(() => loading.value || !!errorMsg.value)

/** 组装 4 段式通道编码：channelId 含 $ 则直接使用，否则 deviceId$1$0$channelId（与后端规则一致） */
const buildChannelCode = (cam: any): string => {
  const channelId = cam?.channelId || ''
  if (channelId.includes('$')) return channelId
  return `${cam.deviceId}$1$0$${channelId}`
}

/** WSPlayer 事件回调（签名：method, data, err） */
const onMessage = (method: string, data: any, err: any) => {
  switch (method) {
    case 'initializationCompleted':
      initialized = true
      if (initTimeout) { clearTimeout(initTimeout); initTimeout = null }
      loadingText.value = '正在连接视频流...'
      // 初始化完成后播放等待中的摄像头
      if (pendingCamera) {
        const cam = pendingCamera
        pendingCamera = null
        doPlay(cam)
      } else if (pendingCameraList) {
        const list = pendingCameraList
        pendingCameraList = null
        playList(list)
      }
      break
    case 'realSuccess':
      playing = true
      loading.value = false
      errorMsg.value = null
      break
    case 'realError': {
      playing = false
      loading.value = false
      const info = data?.apiErrorInfo || data || {}
      errorMsg.value = info.errorMsg || info.message || '视频流播放失败'
      break
    }
    case 'talkSuccess':
      break // 对讲成功（HTTPS 环境下可用）
    case 'talkError':
      // HTTP 页面浏览器禁用麦克风时对讲不可用，属预期行为（HTTPS 部署后自动可用）
      console.warn('[WSPlayer] 对讲失败（HTTP 环境麦克风受限，HTTPS 部署后可用）:', data)
      break
    case 'selectWindowChanged':
      currentWindowIndex.value = data.playIndex ?? data.selectIndex ?? 0
      break
    case 'closeVideo':
      // 用户点击播放器内的关闭按钮（切换视频引发的关闭不通知）
      if (data && !data.changeVideoFlag) {
        if (Date.now() < internalCloseUntil) return
        emit('close')
      }
      break
    case 'errorInfo':
      console.error('[WSPlayer] 错误信息:', data)
      break
    default:
      break
  }
}

/** 播放指定摄像头（windowIndex 指定目标窗口，缺省使用当前活动窗口） */
const doPlay = (cam: any, windowIndex?: number) => {
  if (!pm) return
  const channelCode = buildChannelCode(cam)
  // channelSeq 取 4 段式最后一段（对讲用）
  const channelSeq = channelCode.split('$').pop() || '0'
  const channelList = [
    {
      id: channelCode,          // 通道编码（预览必填）
      deviceCode: cam.deviceId, // 设备编码（对讲必填）
      deviceType: cam.deviceType || '1',
      channelSeq,               // 通道序号（对讲必填）
      cameraType: cam.cameraType || '1',
      capability: cam.capability || ''
    }
  ]
  loading.value = true
  loadingText.value = '正在连接视频流...'
  errorMsg.value = null
  // 替换已有窗口视频会触发 closeVideo 事件，抑制此期间的 close 通知（非用户主动关闭）
  internalCloseUntil = Date.now() + 800
  try {
    pm.playRealVideo({
      channelList,
      streamType: cam.quality || '2', // 码流类型：1-主码流 2-辅码流1
      windowIndex: windowIndex ?? currentWindowIndex.value
    })
  } catch (e: any) {
    loading.value = false
    errorMsg.value = e.message || '播放失败'
  }
}

/** 批量播放：关闭全部窗口后，依次将在线摄像头播放到窗口 0..N-1 */
const playList = (list: any[]) => {
  if (!pm) return
  loading.value = true
  loadingText.value = '正在连接视频流...'
  errorMsg.value = null
  internalCloseUntil = Date.now() + 800
  try { pm.close() } catch (e) { /* ignore */ }
  if (!list.length) { loading.value = false; return }
  const onlines = list.filter((c) => c.status !== 0)
  onlines.slice(0, 9).forEach((cam, i) => doPlay(cam, i))
}

const stopPlay = (windowIndex?: number) => {
  playing = false
  pendingCamera = null
  if (pm) {
    try { pm.close(windowIndex ?? currentWindowIndex.value) } catch (e) { /* ignore */ }
  }
}

const retry = () => {
  if (props.camera) doPlay(props.camera)
  else errorMsg.value = null
}
```

## 六、部署配置（nginx）

HTTPS 页面下浏览器禁止混合内容（`https` 页面不能连 `ws://`），且部分 ICC 环境 9102（wss）端口不可用，因此用 nginx 同源反向代理转发到流媒体 9100：

```nginx
# WSPlayer 视频流 WebSocket 代理（HTTPS 页面 wss 转发到 ICC 流媒体 9100）
location /wsplayer-proxy {
    proxy_pass http://**:9100/;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_read_timeout 3600s;
    proxy_send_timeout 3600s;
    proxy_connect_timeout 30s;
    proxy_buffering off;
}
```

> 复用到新系统时：把 `proxy_pass` 的 IP 换成新环境的流媒体服务器 IP 即可，前端代码无需改动。

## 八、已知坑与注意事项

1. **通道编码必须 4 段式**：ICC 要求 `deviceId$1$0$channelSeq`。后端与前端都做了"含 `$` 则直接用，否则自动补全"的兼容处理，两边规则必须一致。

2. **token 是一次性的**：StartVideo 返回的 token 30 秒内有效且仅能使用一次。因此**每次切流/重连都必须重新调用 `/start-video`**（由 WSPlayer 的 `getRealmonitor` 回调自动完成），不能缓存复用。

3. **https 页面的混合内容问题**：https 页面不能直连 `ws://`；且部分 ICC 环境 9102 端口的 wss 不可用（自签名证书被浏览器拦截）。解决方案即 nginx `/wsplayer-proxy` 同源代理（见第六章）。`setWSUrl` 回调按 `location.protocol` 自适应。

4. **`prefixUrl` 前导斜杠陷阱**：WSPlayer 内部 `processPrefixUrl` 对以 `/` 开头的值会再加一个 `/`（变成 `//static`），必须传 `'static'` 或 `'./static'`。

5. **hutool JSON 的 JSONNull**：`JSONUtil.toBean` 会把 JSON `null` 解析为 `JSONNull` 对象，直接 `(String)` 强转会抛 `ClassCastException`，必须用 `strOrNull()` 统一转换。

6. **RSA 密码分段加密**：ICC 公钥为 RSA 2048，单块最大加密 117 字节，密码超长时必须分段加密后拼接（见 `doEncryptPassword`）。

7. **对讲需要 HTTPS**：浏览器的麦克风权限要求安全上下文。HTTP 页面下 `talkError` 属预期行为（播放不受影响），HTTPS 部署后自动可用。

8. **批量播放的 closeVideo 抑制**：批量播放前调用 `pm.close()` 全关窗口会触发 `closeVideo` 事件，需要用时间窗口（`internalCloseUntil`）抑制，避免误清空父组件的播放状态；切换视频引发的关闭另有 `changeVideoFlag` 标志可区分。

9. **Token 提前 5 分钟刷新**：`isTokenValid()` 判断时会提前 300 秒认为过期，避免边界期请求失败；`refreshToken` 用双检锁防并发重复刷新。

10. **WSPlayer 初始化时机**：文档要求在 `mounted` 生命周期 `nextTick` 中执行 `new PlayerManager()`；组件需处理"摄像头已选中但播放器未初始化完成"的挂起场景（`pendingCamera`），并设置 8 秒兜底超时报资源加载失败。
