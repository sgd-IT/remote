# 安威远程监控系统 — 部署操作手册

---

## 一、目录结构

```
deploy/
├── .env                          # 环境变量（Harbor地址、镜像版本、云数据库密码等）
├── .gitignore                    # Git忽略规则（.env、data/、*.log 不提交）
├── build-push.ps1                # 【开发机Windows】构建并推送镜像到Harbor
├── pull-images.sh                # 【目标服务器】从Harbor拉取镜像
├── start-services.sh             # 【目标服务器】启动/停止服务
├── docker-compose.yml            # 主编排文件（3个服务）
├── config/
│   ├── frontend/nginx.conf       # Nginx反向代理配置
│   ├── server/application-prod.yaml       # 后端生产配置
│   └── tdengine/taos.cfg         # TDengine配置
├── init/
│   ├── init.sql                  # MySQL初始化脚本（云MySQL手动导入）
│   └── init_td.sql               # TDengine初始化脚本
└── registry/
    └── docker-compose.yml        # 本地Docker Registry（可选，离线场景）
```

---

## 二、服务架构

| 分类 | 服务名 | 容器名 | 端口映射 | 说明 |
|------|--------|--------|----------|------|
| 基础设施 | tdengine | anwei-tdengine | 6030, 6041 | TDengine 3.x 时序数据库 |
| 应用服务 | server | anwei-remote-monitor | 48080 | 后端服务（JDK 21） |
| 应用服务 | nginx-frontend | anwei-frontend | 80 | 前端 + API反向代理 |

> **MySQL 和 Redis 使用云服务**，不在本地 Docker 中部署。连接信息在 `.env` 中配置。

**服务依赖关系：**
```
nginx-frontend → server → tdengine（healthy）
                        → 云MySQL
                        → 云Redis
```

## 三、操作步骤

### 3.1 开发机（Windows）：构建并推送镜像

> 脚本：`build-push.ps1`
> 前置条件：JDK 21、Maven、Git、Docker Desktop 已安装

```powershell
cd <项目deploy目录>

# 必须指定版本号，其余路径参数可自动检测
.\build-push.ps1 -Version v1.0

# 也可指定自定义路径
.\build-push.ps1 -Version v1.0 -JDK "D:\Java\jdk-21" -FrontendDir "D:\project\anwei-remote-monitor-ui"
```

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| -Version | 镜像版本号（必填） | 无 |
| -ACR | Harbor仓库地址 | **:8800/anwei-remote-monitor |
| -BackendDir | 后端项目目录 | 脚本上级目录 |
| -FrontendDir | 前端项目目录 | 自动检测同级目录 |
| -JDK | JDK安装目录 | 自动检测JAVA_HOME/PATH |
| -BackendBranch | 后端Git分支 | master |
| -FrontendBranch | 前端Git分支 | master |

**交互式构建目标选择：**

```
========================================
  请选择构建目标
========================================
  1. 全部构建  （前端 + 后端）
  2. 只构建后端 （anwei-remote-monitor）
  3. 只构建前端 （nginx-frontend）
========================================
请输入序号 [1-3]:
```

---

### 3.2 目标服务器：拉取镜像

> 脚本：`pull-images.sh`
> 前置条件：Docker 已安装，能访问 Harbor 仓库

```bash
cd <deploy目录>
chmod +x pull-images.sh
./pull-images.sh
```

**交互式拉取目标选择：**

```
========================================
  请选择拉取目标
========================================
  1. 全部拉取  （基础设施 + 应用镜像）
  2. 只拉取应用镜像 （server + frontend）
  3. 只拉取基础设施镜像 （tdengine）
  4. 只拉取 anwei-remote-monitor
  5. 只拉取 nginx-frontend
  6. 只拉取 TDengine
========================================
请输入序号 [1-6]:
```

### 3.3 配置环境变量

编辑 `.env` 文件，按实际环境修改：

```ini
# Harbor地址
HARBOR_HOST=**:8800

# 基础设施镜像仓库
ACR_INFRA=**:8800/library

# 应用镜像仓库
ACR_REGISTRY=**:8800/anwei-remote-monitor

# ★ 镜像版本号（每次发版更新）
SERVER_VERSION=v1.0
FRONTEND_VERSION=v1.0

# TDengine 配置
TDENGINE_USERNAME=root
TDENGINE_PASSWORD=**
TDENGINE_DB=aw_fire_remote_monitor

# ★ 云 MySQL 配置（请根据实际环境修改）
MYSQL_HOST=**
MYSQL_PORT=26671
MYSQL_DB=anwei_fire_remote_monitor
MYSQL_USERNAME=root
MYSQL_PASSWORD=your_password

# ★ 云 Redis 配置（请根据实际环境修改）
REDIS_HOST=gz-crs-luewokn8.sql.tencentcdb.com
REDIS_PORT=26895
REDIS_DATABASE=10
REDIS_PASSWORD=your_password
```

### 3.4 按需修改应用配置

| 配置文件 | 关键配置项 |
|----------|-----------|
| `config/server/application-prod.yaml` | TDengine地址、MQTT配置、各对接平台参数 |
| `config/frontend/nginx.conf` | API反向代理地址（默认指向Docker内网 `server:48080`） |
| `config/tdengine/taos.cfg` | TDengine运行参数 |

> 注意：云MySQL/Redis的连接信息通过 `.env` 环境变量注入，无需修改 yaml 文件。

### 3.5 首次部署

```bash
# 1. 拉取镜像
./pull-images.sh    # 选择 1（全部拉取）

# 2. 初始化 TDengine 数据库
docker-compose up -d tdengine
# 等待 TDengine 启动完成
sleep 15
docker exec anwei-tdengine taos -s "source /init/init_td.sql"

# 3. 启动所有服务
./start-services.sh

# 4. 查看服务状态
./start-services.sh status
```

**首次启动说明：**
- TDengine 首次启动需手动执行初始化脚本创建数据库
- TDengine 有健康检查，server 会在 healthy 后才启动
- 数据持久化到 Docker volume（tdengine_data）和 `./data/` 目录

### 3.7 更新发版

```bash
# 1. 开发机：构建新版本镜像
.\build-push.ps1 -Version v1.2    # 选择对应的构建目标

# 2. 目标服务器：拉取新镜像
./pull-images.sh            # 选择对应的拉取目标

# 3. 修改 .env 中的版本号
#    SERVER_VERSION=v1.2  （仅修改需要更新的服务版本号）

# 4. 重启对应服务
docker-compose up -d server   # 只更新指定服务
# 或全部更新
docker-compose up -d
```

---

### 3.8 常用操作

```bash
# 启动所有服务
./start-services.sh start

# 停止所有服务
./start-services.sh stop

# 重启所有服务
./start-services.sh restart

# 查看服务状态
./start-services.sh status

# 查看实时日志
./start-services.sh logs

# 重启单个服务
docker-compose restart server

# 查看某个服务日志
docker-compose logs -f server

# 清理旧镜像
docker image prune -f

# 停止并删除所有容器（保留数据）
docker-compose down

# 停止并删除数据卷（⚠️ 会丢失所有持久化数据）
docker-compose down -v
```

## 四、离线部署（可选）

如目标服务器无法访问外网/内网Harbor，可使用本地Registry：

```bash
# 1. 启动本地Registry
cd registry
docker-compose up -d    # 启动 registry:2，监听 5000 端口

# 2. 在有网络的机器上拉取镜像后导出
docker save -o images.tar \
  **:8800/anwei-remote-monitor/anwei-remote-monitor:v1.0 \
  **:8800/anwei-remote-monitor/nginx-frontend:v1.0 \
  **:8800/library/tdengine:3.0.7.1

# 3. 传输到目标服务器后导入
docker load -i images.tar

# 4. 按需重新tag并push到本地Registry
docker tag **:8800/anwei-remote-monitor/anwei-remote-monitor:v1.0 localhost:5000/anwei-remote-monitor:v1.0
docker push localhost:5000/anwei-remote-monitor:v1.0
```

## 五、注意事项

1. **`.env` 文件已被 `.gitignore` 忽略**，不会提交到Git，需手动管理
2. **云MySQL/Redis** 连接信息在 `.env` 中配置，通过环境变量注入到应用容器
3. **TDengine数据** 持久化在 Docker volume `tdengine_data`，`docker-compose down -v` 会删除
4. **版本号一致性**：`.env` 中的版本号需与Harbor中实际推送的镜像tag一致
5. **TDengine初始化**：首次部署需手动执行 `init_td.sql` 创建数据库
6. **选择性构建**：`build-push.ps1` 支持交互式菜单选择构建目标
7. **选择性拉取**：`pull-images.sh` 同样支持交互式菜单，更新单个服务时无需拉取全部镜像
8. **脚本权限**：部署前需执行 `chmod +x *.sh` 赋予执行权限
