## 1. 模块概述

### 1.1 模块定位

查岗管理模块（F7）是智慧消防远程值守系统的重要监督保障模块，承担对联网单位消防控制室值班情况进行远程监督检查的职责。通过"手动查岗+定时查岗+AI智能查岗"三位一体的查岗机制，确保消防控制室24小时持证值班制度落到实处，及时发现和纠正脱岗、离岗行为，提升联网单位消防安全管理水平。

### 1.2 业务目标

| 目标维度 | 量化指标 | 达标时间 |
|---------|---------|---------|
| 查岗覆盖率 | 重点单位月度查岗覆盖率≥100% | 系统上线3个月 |
| 值班合规率 | 持证上岗率≥99% | 持续运营 |
| 脱岗发现率 | AI自动发现率≥90% | 上线6个月 |
| 查岗响应率 | 有效响应率≥95% | 系统上线即达标 |
| 查岗闭环率 | 异常查岗闭环率≥98% | 持续运营 |

## 2. 用户角色与场景

### 2.1 用户角色定义

| 角色名称 | 职责描述 | 使用终端 |
|---------|---------|---------|
| 远程值守员 | 执行日常查岗任务，监督联网单位值班情况 | 值守大屏、Web端 |
| 查岗管理员 | 配置查岗规则，统计查岗数据，处理异常情况 | Web管理后台 |
| 联网单位负责人 | 接收查岗通知，督促整改脱岗问题 | 移动端 |
| 消控室值班员 | 接收并应答查岗，配合远程监督 | 值守主机、移动端 |
| 消防监管人员 | 抽查重点单位值班情况，监督整改 | 移动端、Web端 |

### 2.2 典型业务场景

**场景1：定时自动查岗**  
系统按照排班计划，于每天凌晨3点向所有联网单位消控室值守屏推送"自动查岗"指令，某商场消控室值班员王丽点击"应答"按钮完成签到，系统记录应答时间2秒，查岗任务完成。

**场景2：离岗AI识别**  
某小区消控室监控视频中，值班人员离开座位超过5分钟，AI系统自动识别并生成离岗告警，值守中心大屏弹出告警提示，值守员李明电话联系该值班员确认情况，确认为上厕所临时离开后记录在案。

**场景3：脱岗升级处理**  
凌晨4点，某写字楼消控室连续3次查岗无应答，系统自动升级通知该单位消防安全管理人张某，张某联系值班员确认为睡岗，立即安排换岗。系统记录完整查岗及处理过程，形成合规台账。

**场景4：消防专项查岗**  
重大活动安保期间，消防监管部门发起对辖区所有重点单位的专项查岗，系统自动下发查岗通知，2小时内完成对200家单位的查岗，结果汇总后生成专项报告。

## 3. 功能需求详述

### 3.1 F7.1 查岗类型（P1）

#### 3.1.1 功能描述

系统支持三种查岗类型：手动查岗、定时查岗、AI自动查岗，满足不同场景下的值班监督需求。

#### 3.1.2 手动查岗

| 属性 | 说明 |
|-----|------|
| 触发方式 | 值守员主动发起 |
| 适用场景 | 随机抽查、专项检查、节假日重点监督 |
| 响应方式 | 消控室值守屏弹窗+移动端APP推送 |
| 超时时间 | 可配置（默认5分钟） |
| 升级机制 | 超时无应答自动升级至单位负责人 |

**操作流程**：
1. 值守员选择查岗对象（单选/批量）
2. 填写查岗说明（可选）
3. 确认发起查岗
4. 等待值班员应答
5. 记录应答结果
6. 超时升级处理
7. 查岗记录归档

#### 3.1.3 定时查岗

| 属性 | 说明 |
|-----|------|
| 触发方式 | 系统按排班计划自动执行 |
| 适用场景 | 日常值班监督、夜间重点时段监控 |
| 查岗时段 | 可配置（默认0:00/4:00/8:00/12:00/16:00/20:00） |
| 排班配置 | 支持按单位、按人员配置不同查岗计划 |
| 响应方式 | 值守屏弹窗+移动端推送 |
| 超时时间 | 可配置（默认5分钟） |

**排班配置规则**：
| 查岗时段 | 适用单位类型 | 重点监督 |
|---------|-------------|---------|
| 0:00-6:00 | 所有单位 | 夜间睡岗 |
| 6:00-12:00 | 重点单位 | 早班交接 |
| 12:00-18:00 | 重点单位 | 午间脱岗 |
| 18:00-24:00 | 人员密集场所 | 晚班脱岗 |

#### 3.1.4 AI自动查岗

| 属性 | 说明 |
|-----|------|
| 触发方式 | AI视频分析检测到离岗风险自动触发 |
| 适用场景 | 消控室人员离岗、睡岗、长时间异常动作 |
| 检测类型 | 离岗（离开座位≥N分钟可配置）、睡岗（低头≥N分钟）、长时间离位 |
| 响应方式 | 告警→人工复核→确认离岗→通知整改 |
| 检测依据 | 消控室监控视频 |

**AI检测规则**：
| 检测类型 | 检测条件 | 默认阈值 | 可配置范围 |
|---------|---------|---------|-----------|
| 离岗检测 | 人员离开座位区域 | 3分钟 | 1-10分钟 |
| 睡岗检测 | 头部姿态持续向下 | 5分钟 | 2-15分钟 |
| 长时间离位 | 人员离开画面区域 | 10分钟 | 5-30分钟 |
| 多人同时离岗 | 消控室人员全部离开 | 1分钟 | 0.5-5分钟 |

#### 3.1.5 交互流程

**手动查岗流程**：
```
[值守员发起查岗] → [查岗指令下发] → [值守屏+移动端接收]
                                              ↓
                                    ┌─────────┴─────────┐
                                    ↓                   ↓
                              [5分钟内应答]         [超时无应答]
                                    ↓                   ↓
                              [记录有效查岗]      [升级通知负责人]
                                    ↓                   ↓
                              [查岗完成]           [确认脱岗→整改]
                                                     ↓
                                               [记录归档]
```

**AI自动查岗流程**：
```
[视频流接入] → [AI离岗检测] → [检测到离岗] → [生成AI预警]
                                              ↓
[人工复核] ← [值班员确认] ← [通知值班员] ← [告警推送]
      ↓
[误报确认] ← [核实为正常离开] → [确认离岗] → [记录脱岗]
      ↓                              ↓
[标注误报]                      [整改跟踪]
```

#### 3.1.6 输入输出规范

**输入数据**：
- 联网单位信息（单位ID、名称、消控室数量、联系人）
- 排班计划（值班人员、排班时间）
- 查岗配置（查岗时段、超时时间、升级规则）
- 视频流（消控室监控视频）

**输出数据**：
- 查岗任务（查岗编号、对象、时间、类型）
- 查岗记录（应答状态、应答时间、处理结果）
- 查岗统计（查岗次数、响应率、脱岗率）
- 查岗台账（可导出PDF/Excel）

#### 3.1.8 验收标准

**AC-F7.1-001：手动查岗功能**  
- **验收条件**：支持单选/批量发起查岗，支持配置查岗说明，指令下发≤3秒送达  
- **测试方法**：分别测试单选和批量查岗，测量指令下发时间

**AC-F7.1-002：定时查岗功能**  
- **验收条件**：按排班计划自动执行查岗，支持按单位、人员差异化配置  
- **测试方法**：配置多个定时查岗任务，观察执行情况

**AC-F7.1-003：AI自动查岗**  
- **验收条件**：检测到离岗后30秒内生成预警，支持白名单配置（喝水、如厕）  
- **测试方法**：模拟离岗场景，验证检测准确性和告警及时性

**AC-F7.1-004：查岗响应机制**  
- **验收条件**：超时无应答自动升级，升级通知≤60秒送达  
- **测试方法**：模拟超时场景，验证升级机制

### 3.2 F7.2 查岗流程（P1）

#### 3.2.1 功能描述

实现完整的查岗业务流程，包括查岗指令下发、应答处理、超时升级、结果记录等全流程管理。

#### 3.2.2 查岗流程步骤

| 步骤 | 环节 | 执行角色 | 操作内容 | 时限要求 |
|-----|------|---------|---------|---------|
| 1 | 查岗发起 | 值守员/系统 | 选择对象、确认发起 | 即时 |
| 2 | 指令下发 | 系统 | 推送至值守屏+移动端 | ≤3秒 |
| 3 | 应答等待 | 值班员 | 收到通知后点击应答 | 5分钟 |
| 4 | 有效应答 | 值班员 | 点击确认按钮 | ≤60秒 |
| 5 | 记录生成 | 系统 | 自动生成查岗记录 | 即时 |
| 6 | 超时判断 | 系统 | 超时则触发升级 | 5分钟 |
| 7 | 升级通知 | 系统 | 通知单位负责人 | ≤60秒 |
| 8 | 脱岗确认 | 负责人 | 确认脱岗情况 | 可配置 |
| 9 | 整改跟踪 | 值守员/负责人 | 督促整改 | 24小时 |
| 10 | 记录归档 | 系统 | 归档形成台账 | 即时 |

#### 3.2.3 应答方式

| 应答方式 | 说明 | 适用场景 |
|---------|------|---------|
| 值守屏应答 | 在消控室值守屏点击"确认"按钮 | 正常值班 |
| 移动APP应答 | 通过手机APP点击确认 | 移动巡查 |
| 人脸识别应答 | 扫脸确认（需设备支持） | 高安全要求 |
| 口令应答 | 输入值班口令 | 网络异常备用 |
| 短信应答 | 回复指定短信验证码 | 极端情况 |

#### 3.2.4 超时升级机制

| 超时次数 | 升级对象 | 通知方式 | 处理要求 |
|---------|---------|---------|---------|
| 第1次超时 | 值班员 | 值守屏+APP+短信 | 再次提醒应答 |
| 第2次超时 | 单位消防安全管理人 | APP+短信+电话 | 确认值班情况 |
| 第3次超时 | 单位主要负责人 | 短信+电话 | 紧急处理 |
| 确认脱岗 | 辖区消防监管部门 | 系统推送 | 执法检查 |

#### 3.2.5 升级规则配置

```yaml
升级策略:
  夜间(23:00-6:00):
    第1次超时: 3分钟
    第2次超时: 5分钟
    升级方式: APP+短信+自动语音电话
  白天(6:00-23:00):
    第1次超时: 5分钟
    第2次超时: 10分钟
    升级方式: APP+短信
  重点时期:
    超时时间减半
    升级范围扩大一级
```

#### 3.2.6 脱岗记录管理

| 脱岗类型 | 说明 | 处理方式 |
|---------|------|---------|
| 临时离岗 | 短时间离开（≤10分钟） | 记录+提醒 |
| 睡岗 | 长时间无操作疑似睡岗 | 记录+预警+整改 |
| 脱岗 | 无故离开消控室 | 记录+升级+整改 |
| 无人值班 | 消控室空无一人 | 记录+升级+执法 |

#### 3.2.10 验收标准

- **验收条件**：从查岗发起到归档全流程可追溯，每个节点有时间戳记录

- **验收条件**：超时自动升级，升级通知≤60秒送达，支持多级升级

- **验收条件**：脱岗记录包含时间、地点、人员、脱岗时长、关联录像截图  
- **测试方法**：查询历史脱岗记录，核对信息完整性

**AC-F7.2-004：整改闭环管理**  
- **验收条件**：支持整改任务派发、整改确认、整改证明上传完整闭环

3. 支持按单位/区域/行业筛选
4. 图表支持点击下钻（点击单位查看详情）
