## 1. 模块概述

### 1.1 定位
权限与安全模块（F9）是智慧消防远程值守系统的安全保障核心模块，承担用户身份认证、权限管理、安全审计与网络安全四大职能。依据T/CFPA 052-2026《消防设施操作员远程值守能力评价规范》建立三级权限体系，依据T/GDCAA 016-2025《建筑消防设施远程控制技术规程》构建安全控制机制，依据GB 25201-2010《建筑消防设施的维护管理》落实日常安全管理要求，确保远程值守业务的合规性、安全性与可追溯性。

### 1.2 业务目标

| 目标层级 | 具体目标 |
|----------|----------|
| 安全目标 | 用户身份认证100%、权限验证覆盖率100%、安全红线零违反 |
| 合规目标 | 三级权限体系100%符合标准、证书过期自动停岗、值守员资质100%合规 |
| 审计目标 | 操作留痕100%、日志不可篡改、审计追溯≥5年 |
| 防护目标 | 等级保护≥二级、网络攻击防护率≥99.9% |

### 1.3 合规依据

| 标准编号 | 标准名称 | 适用条款 |
|----------|----------|----------|
| T/CFPA 052-2026 | 消防设施操作员远程值守能力评价规范 | 第5节人员资质、第6节权限管理、第8节安全要求 |
| T/GDCAA 016-2025 | 建筑消防设施远程控制技术规程 | 第5节安全要求、第7节控制安全 |
| GB 25201-2010 | 建筑消防设施的维护管理 | 第6节值班要求、第7节安全管理 |

### 2.1 用户角色定义

#### 2.1.1 三级权限体系

| 角色等级 | 岗位名称 | 系统角色ID | 权限概述 | 典型操作 |

### 2.2 典型业务场景

#### 场景一：值守员日常值班
- **触发条件**：值守员登录系统开始值班
- **操作路径**：登录验证 → 火警监测 → 误报处置 → 值班记录 → 交接班
- **权限要求**：普通权限（L1）
- **标准依据**：T/CFPA 052-2026 第5.2条；GB 25201-2010 第6.1条

#### 场景二：高风险设备控制
- **触发条件**：需要远程启动消防泵
- **操作路径**：发起控制请求 → 业主授权 → 第一操作员确认 → 第二复核员确认 → 命令下发 → 结果确认
- **权限要求**：操作权限（L2）+ 业主授权 + 双人复核
- **标准依据**：T/CFPA 052-2026 第6.2条；T/GDCAA 016-2025 第7.2条

#### 场景三：值守员资质管理
- **触发条件**：值守员证书即将过期
- **操作路径**：系统自动检测 → 预警提醒 → 续证办理 → 新证书上传 → 资质重新认证
- **权限要求**：管理权限（L3）
- **标准依据**：T/CFPA 052-2026 第5.3条；消防法第21条

#### F9.1.2 角色配置管理

|------|------|

#### F9.1.4 权限继承与冲突处理

|------|------|
| **功能描述** | 处理多角色权限继承和冲突场景 |
| **业务规则** | - 高等级角色权限自动覆盖低等级<br>- 显式拒绝权限优先于允许权限<br>- 临时权限在到期后自动失效<br>- 权限冲突时取最小权限集 |
| **冲突类型与处理策略** | |

| 类型二：临时权限与永久权限冲突 | 处理：临时权限在有效期内优先 |
| 类型三：数据范围冲突 | 处理：取交集 |
| **验收标准** | AC-F9.1.4-01：权限冲突检测准确率100%<br>AC-F9.1.4-02：冲突处理策略符合安全原则<br>AC-F9.1.4-03：冲突处理记录完整可查 |
| **标准依据** | T/CFPA 052-2026 第6.1.5条 |

```
[证书到期前30天] → 发送预警通知 → 用户处理
        ↓
[证书到期前7天] → 发送紧急预警 → 管理员介入
        ↓
[证书到期当日] → 自动停用账号 → 禁止登录
        ↓
```

- AC-F9.2.3-04：新证书上传后账号恢复时间≤10分钟
