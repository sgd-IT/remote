**文档版本**：V1.0  
**编写日期**：2025年  
**状态**：草稿

**标准依据**：GB 50440-2007、GB/T 26875.1-2026、T/GDCAA 016-2025

## 1. 模块概述

### 1.1 模块定位

监测预警模块（F3）是智慧消防远程值守系统的核心感知层，负责实时采集、汇聚、分析消防设施运行状态数据，实现对火灾报警、消防给水、电气火灾、防排烟、消防电源等15类消防设施的全天候在线监测，并基于AI技术实现智能风险预警，将传统的被动式响应转变为主动式预防。

### 1.2 业务目标

| 目标维度 | 量化指标 | 达标时间 |
|---------|---------|---------|
| 监测覆盖率 | 接入传输装置在线率≥95% | 系统上线3个月内 |
| 设备完好率 | 联网设备完好率≥90% | 持续运营 |
| 预警准确率 | AI预警准确率≥85% | 上线6个月后 |
| 响应时效 | 告警到通知≤60秒 | 系统上线即达标 |
| 漏报率 | 重要告警漏报率≤0.1% | 持续运营 |

### 1.3 合规依据

| 依据编号 | 标准名称 | 适用条款 |
|---------|---------|---------|
| GB 50440-2007 | 城市消防远程监控系统技术规范 | 第4.2条监测功能、第5.2条系统设计 |
| GB/T 26875.1-2026 | 城市消防远程监控系统 第1部分：信息采集 | 附录A设施分类、附录B数据格式 |
| T/GDCAA 016-2025 | 智慧消防建设技术规范 | 第6.3条监测预警、第8.2条数据留存 |
| T/CFPA 052-2026 | 消防设施物联网系统运行平台 | 第5.1条运行监测要求 |

## 2. 用户角色与场景

### 2.1 用户角色定义

| 角色名称 | 职责描述 | 使用终端 |
|---------|---------|---------|
| 远程值守员 | 7×24小时监控消防设施状态，接收并初步处理告警信息 | 值守大屏、Web端 |
| 消防安全管理人 | 监督设施运行状况，审批重大告警处理方案 | Web端、移动端 |
| 联网单位值班员 | 本地接收告警并现场核查处置 | 移动端、值守主机 |
| 系统运维工程师 | 维护传输装置运行，处理设备离线故障 | 运维管理后台 |
| AI算法工程师 | 优化预警模型，调整识别规则 | 算法配置后台 |

### 2.2 典型业务场景

**场景1：火灾报警实时监测**  
值守员李明在值守中心大屏上看到某商场消防主机推送的"2区火警"信息，系统自动关联该区域3个摄像头弹出实时画面，确认为真实火警后立即启动应急预案，通知119消防指挥中心。

**场景2：设备异常预警**  
某酒店消防水泵运行数据出现异常波动（压力值在10分钟内下降15%），AI预警系统识别为管网泄漏风险，生成黄色预警推送至酒店消防负责人，值守中心同步跟踪处置进度。

**场景3：传输装置离线告警**  
凌晨3点，系统检测到某写字楼传输装置离线超过5分钟，自动生成故障告警并通知运维工程师，运维人员远程排查确认网络故障，30分钟内恢复通信。

**场景4：消防通道堵塞检测**  
AI视频分析检测到某住宅小区消防通道被私家车占用，系统自动抓拍取证，生成违规记录推送至物业管理人员，同步在平台形成隐患台账。

## 3. 功能需求详述

### 3.1 F3.1 实时状态监测（P0）

#### 3.1.1 功能描述

实时采集并展示消防设施运行状态数据，覆盖15类核心消防设施，参照GB/T 26875.1-2026附录A标准分类。

#### 3.1.2 设施分类清单

| 设施类别 | 监测点位 | 状态参数 | 数据频率 |
|---------|---------|---------|---------|
| 传输装置 | 通信状态/信号强度/供电状态 | 在线/离线/故障/通信质量 | 实时 |
| 火灾报警系统 | 报警主机 | 火警/故障/监管/屏蔽/联动 | 实时 |
| 消防给水-管网 | 管网压力监测点 | 压力值(MPa)/变化趋势 | 每30秒 |
| 消防给水-水池 | 液位传感器 | 水位高度(m)/溢流状态 | 每分钟 |
| 消防给水-水泵 | 水泵控制柜 | 运行/停止/故障/手自动状态 | 实时 |
| 防排烟-风机 | 风机控制柜 | 运行状态/转速/振动/温度 | 每10秒 |
| 防排烟-阀门 | 电动防火阀 | 开度/故障/联动状态 | 每分钟 |
| 消防电源 | 双电源切换装置 | 主电/备电状态/电压/电流/频率 | 每分钟 |
| 防火门 | 电动防火门 | 开闭状态/故障/门磁状态 | 每30秒 |
| 防火卷帘 | 卷帘门控制器 | 上行/下行/停止/故障 | 实时 |
| 电气火灾监控 | 剩余电流探测器 | 剩余电流值/温度/报警阈值 | 每分钟 |
| 气体灭火 | 气体灭火控制器 | 启动/停止/故障/压力状态 | 实时 |
| 应急照明 | 应急照明控制器 | 工作状态/照度/电池状态 | 每5分钟 |
| 消防广播 | 消防广播控制器 | 工作状态/分区状态 | 每分钟 |
| 智能分析终端 | 视频分析单元 | AI识别结果/报警状态 | 实时 |

#### 3.1.3 交互流程

```
[消防设施] → [传输装置/采集网关] → [数据汇聚平台] → [实时监测引擎]
                                       ↓
                                  [状态展示层]
                                       ↓
[值守员大屏] ← [Web管理后台] ← [移动端APP]
```

#### 3.1.4 输入输出规范

**输入数据**：
- 设施编码（按GB/T 26875.1-2026附录B.2编码规则）
- 监测点位ID
- 采集时间戳（UTC+8，毫秒精度）
- 状态值（整数/浮点/枚举）

**输出数据**：
- 实时状态页面（刷新周期≤3秒）
- 历史曲线图（支持1小时/24小时/7天/30天）
- 状态变更记录
- 异常告警通知

#### 3.1.5 业务规则

| 规则编号 | 规则描述 | 标准来源 |
|---------|---------|---------|
| BR-F3.1-001 | 传输装置通信协议应符合GB/T 26875.1-2026第6章规定的数据接口规范 | GB/T 26875.1-2026 6.2 |
| BR-F3.1-002 | 火警信息从产生到平台接收延迟≤10秒 | GB 50440-2007 5.2.3 |
| BR-F3.1-003 | 消防设施状态数据采集周期：重要设施≤60秒，一般设施≤5分钟 | T/GDCAA 016-2025 6.3.2 |
| BR-F3.1-004 | 设施编码采用20位标准编码：6位单位+4位系统+4位类型+6位序号 | GB/T 26875.1-2026 附录B.2 |
| BR-F3.1-005 | 状态数据应包含时间戳、设备ID、状态值、采集单位、校验码 | GB/T 26875.1-2026 B.3.1 |
| BR-F3.1-006 | 系统应支持至少10000个监测点位的并发接入 | GB 50440-2007 4.2.2 |

#### 3.1.6 验收标准

**AC-F3.1-001：传输装置状态监测**  
- **验收条件**：系统能够实时展示传输装置的在线/离线/故障/通信质量状态，离线超过5分钟自动触发告警  
- **测试方法**：断开某传输装置网络连接，观察系统告警触发时间及通知到达时间，验证是否≤5分钟

**AC-F3.1-002：火灾报警信息展示**  
- **验收条件**：接收到火警信息后，平台在≤10秒内完成展示，且支持按单位/时间/类型筛选  
- **测试方法**：模拟推送一条火警数据，测量从接收到展示的时间间隔

**AC-F3.1-003：消防给水数据采集**  
- **验收条件**：管网压力监测数据刷新周期≤30秒，数据精度保留2位小数，单位为MPa  
- **测试方法**：连续监测5个压力点，对比采集值与实际值偏差

**AC-F3.1-004：历史数据查询**  
- **验收条件**：支持查询任意监测点最近12个月的历史数据，查询响应时间≤3秒  
- **测试方法**：分别查询不同时间范围的数据，测量响应时间

**AC-F3.1-005：多维度状态统计**  
- **验收条件**：系统提供按单位、按设施类型、按区域的在线率统计功能  
- **测试方法**：导出统计报表，核对数据准确性

### 3.2 F3.2 设备在线率统计（P1）

#### 3.2.1 功能描述

对联网消防设施的在线状态、完好情况进行统计分析，自动生成设备健康度评估报告，对低于阈值的单位触发预警。

#### 3.2.2 核心指标定义

| 指标名称 | 计算公式 | 告警阈值 | 统计周期 |
|---------|---------|---------|---------|
| 传输装置在线率 | 在线台数/联网总台数×100% | <95%告警 | 日/周/月 |
| 设备完好率 | 正常设备数/联网设备总数×100% | <90%告警 | 月度 |
| 联网单位活跃度 | 有数据上报的单位/应上报单位×100% | <85%告警 | 日 |
| 告警响应率 | 已处理告警/总告警数×100% | <95%告警 | 日 |
| 平均故障修复时间(MTTR) | 故障持续总时长/故障次数 | >4小时告警 | 月度 |

#### 3.2.3 交互流程

```
[数据采集层] → [指标计算引擎] → [阈值比对] → [告警生成]
                                            ↓
[统计报表] ← [可视化展示] ← [告警通知] → [工单派发]
```

#### 3.2.4 输入输出规范

**输入数据**：
- 设备基础信息（设备ID、类型、所属单位、安装位置）
- 设备状态上报记录（时间戳、状态值）
- 告警处理记录（时间、处理人、结果）

**输出数据**：
- 设备在线率日报/周报/月报
- 设备完好率分析报告
- 单位活跃度排名榜单
- 告警响应率统计

#### 3.2.5 业务规则

| 规则编号 | 规则描述 | 标准来源 |
|---------|---------|---------|
| BR-F3.2-001 | 传输装置在线率统计周期为自然日，在线判定标准为24小时内有数据上报 | T/GDCAA 016-2025 6.3.4 |
| BR-F3.2-002 | 设备完好率统计需排除已报废、停用的设备 | T/GDCAA 016-2025 6.3.4 |
| BR-F3.2-003 | 在线率低于95%时应生成黄色预警并通知联网单位消防安全管理人 | GB 50440-2007 5.3.2 |
| BR-F3.2-004 | 设备完好率低于90%时应生成橙色预警并推送至区级消防管理部门 | T/GDCAA 016-2025 6.3.4 |
| BR-F3.2-005 | 统计数据应支持导出为Excel格式，保留3年备查 | T/GDCAA 016-2025 8.2.1 |

#### 3.2.6 验收标准

**AC-F3.2-001：在线率统计准确性**  
- **验收条件**：在线率计算结果与实际数据偏差≤0.1%，支持手动复核  
- **测试方法**：选取5个联网单位，核对系统统计值与实际在线设备数

**AC-F3.2-002：阈值告警触发**  
- **验收条件**：当在线率低于95%或完好率低于90%时，系统自动生成告警并通知相关人员  
- **测试方法**：调整测试设备状态，触发阈值条件，验证告警生成及通知时效

**AC-F3.2-003：统计报表生成**  
- **验收条件**：支持自动生成日报、周报、月报，支持定时推送至指定邮箱  
- **测试方法**：配置报表推送任务，验证邮件接收及内容完整性

**AC-F3.2-004：活跃度排名展示**  
- **验收条件**：按活跃度降序展示联网单位排名，支持按区域/行业筛选  
- **测试方法**：查看排名页面，验证数据排序及筛选功能正确性

### 3.3 F3.3 AI智能预警（P0）

#### 3.3.1 功能描述

基于计算机视觉和机器学习技术，实现消防通道堵塞检测、值班人员离岗识别、火灾风险预测及设备异常趋势分析，将被动响应转变为主动预防。

#### 3.3.2 子功能清单

##### F3.3.1 消防通道堵塞检测

| 属性 | 说明 |
|-----|------|
| 技术路线 | 视频AI分析（目标检测+场景理解） |
| 输入源 | 消控室视频监控、楼道监控、室外消防通道监控 |
| 检测目标 | 车辆（汽车、电动车）、杂物（货架、垃圾箱）、临时堆物 |
| 告警条件 | 堵塞物占用通道面积≥40%且持续时间≥30秒 |
| 输出 | 告警截图、告警位置、堵塞物类型、占用面积比 |

##### F3.3.2 值班人员离岗识别

| 属性 | 说明 |
|-----|------|
| 技术路线 | 视频AI分析（人体姿态检测+区域入侵检测） |
| 输入源 | 消控室主监控画面 |
| 检测目标 | 值守人员离岗/睡岗/长时间不看屏幕 |
| 告警条件 | 值守人员离开消控室≥3分钟（可配置） |
| 输出 | 告警截图、离岗时长、关联摄像头信息 |

##### F3.3.3 火灾风险预测

| 属性 | 说明 |
|-----|------|
| 技术路线 | 多源数据融合+时序预测模型 |
| 输入数据 | 历史报警数据、设备运行数据、气象数据、建筑信息 |
| 预测周期 | 24小时/7天/30天 |
| 风险等级 | 极高(红色)/高(橙色)/中(黄色)/低(绿色) |
| 输出 | 风险预测报告、高风险区域分布、重点关注单位清单 |

##### F3.3.4 设备异常趋势分析

| 属性 | 说明 |
|-----|------|
| 技术路线 | 时序数据分析+异常检测算法 |
| 监测对象 | 水泵运行参数、电气线路参数、风机振动参数 |
| 分析维度 | 趋势分析、同比环比、阈值偏离、周期性异常 |
| 预测维护 | 基于运行数据预测潜在故障，生成维护工单 |

#### 3.3.3 交互流程

**消防通道堵塞检测流程**：
```
[视频流接入] → [AI视频分析] → [堵塞检测] → [告警生成]
                                             ↓
[告警详情] ← [截图标注] ← [位置定位] ← [地图关联]
                                             ↓
                              [推送至物业/消防部门]
```

**火灾风险预测流程**：
```
[多源数据汇聚] → [特征工程] → [风险预测模型] → [风险评级]
                                               ↓
[风险报告生成] ← [区域分布] ← [单位排名] ← [趋势分析]
                                               ↓
                                    [推送给消防安全管理部门]
```

#### 3.3.4 输入输出规范

**输入数据**：
- 视频流地址（RTSP/HLS/WebRTC）
- AI模型配置参数
- 告警阈值设置
- 历史数据样本

**输出数据**：
- 实时告警（推送+展示）
- 告警截图（含AI标注）
- 风险预测报告（PDF/HTML）
- 设备健康度评估

#### 3.3.5 业务规则

| 规则编号 | 规则描述 | 标准来源 |
|---------|---------|---------|
| BR-F3.3-001 | 消防通道堵塞检测应符合GB 50016-2014（2018版）第7.1.8条消防车道要求 | GB 50016-2014 7.1.8 |
| BR-F3.3-002 | 消控室值班人员离岗识别应符合GB 25506-2010第5.1条持证上岗要求 | GB 25506-2010 5.1 |

| BR-F3.3-006 | 设备异常预警准确率应≥80%，误报率应≤15% | T/GDCAA 016-2025 6.3.5 |
| BR-F3.3-007 | AI告警截图应保留原始分辨率及AI分析标注图层 | T/GDCAA 016-2025 8.2.3 |

#### 3.3.6 验收标准

**AC-F3.3-001：消防通道堵塞检测**  
- **验收条件**：检测到通道堵塞后5秒内生成告警，告警准确率≥85%，支持手动复核标注  
- **测试方法**：选取10个测试场景（含正常/堵塞各5个），验证检测准确率

**AC-F3.3-002：离岗识别功能**  
- **验收条件**：值守人员离岗≥3分钟自动告警，告警到通知≤30秒，支持白名单设置
