## 1. 模块概述

### 1.1 模块定位

视频联动模块（F6）是智慧消防远程值守系统的核心可视化支撑层，承担"监"与"控"的双重职责。通过统一接入安防视频与消防视频，实现火灾报警与视频画面的智能关联，支持"火警+视频同步弹出"的秒级复核能力，将传统的人工现场核警转变为一屏通览的远程核警，大幅提升值守效率和火警响应速度。

### 1.2 业务目标

| 目标维度 | 量化指标 | 达标时间 |
|---------|---------|---------|
| 视频接入能力 | 支持≥10000路视频接入 | 系统上线3个月 |
| 火警复核时效 | 火警到视频弹出≤10秒 | 系统上线即达标 |
| 安消联动覆盖率 | 联网重点单位覆盖率≥90% | 上线6个月 |
| 视频在线率 | 月均在线率≥95% | 持续运营 |
| 录像存储完整率 | 告警录像完整率≥99.9% | 持续运营 |

### 1.3 合规依据

| 依据编号 | 标准名称 | 适用条款 |
|---------|---------|---------|
| T/CFPA 052-2026 | 消防设施物联网系统运行平台 | 第5.4条视频联动要求 |
| T/GDCAA 016-2025 | 智慧消防建设技术规范 | 第7.1条视频监控接入、第8.2条数据留存 |
| GB 50116-2013 | 火灾自动报警系统设计规范 | 第3.1条火灾探测器的选择 |
| GA/T 1400 | 公安视频图像信息应用系统 | 视频数据结构要求 |

## 2. 用户角色与场景

### 2.1 用户角色定义

| 角色名称 | 职责描述 | 使用终端 |
|---------|---------|---------|
| 远程值守员 | 通过视频复核火警真实性，远程确认火情 | 值守大屏、Web端 |
| 消防安全管理人 | 查看重点区域视频，监督巡查质量 | Web端、移动端 |
| 联网单位值班员 | 本地查看告警关联视频，配合远程核警 | 值守主机、移动端 |
| 视频运维工程师 | 维护视频设备运行，处理视频故障 | 运维管理后台 |
| 安保监控人员 | 日常视频巡查，发现异常上报 | 安防监控客户端 |

### 2.2 典型业务场景

**场景1：火警视频同步复核（P0核心场景）**  
凌晨2点，某商业综合体消控室火灾报警主机推送"3层餐饮区感烟探测器报警"，值守中心系统自动关联该区域4个摄像头，画面瞬间弹出，值守员张明在10秒内通过视频确认厨房油烟较大导致误报，点击"误报确认"按钮，整个核警过程仅用45秒。

**场景2：消防通道堵塞自动抓拍（P1）**  
AI视频分析检测到某住宅小区消防通道被快递车辆占用，系统自动抓拍3张图片（含时间戳和位置标注），生成隐患记录推送至物业管理人员，物业整改后上传整改照片形成闭环。

**场景3：消防巡查远程监督（P1）**  
消防安全管理人通过移动端抽查联网单位消控室值班情况，查看实时视频并抓拍存档。系统自动记录巡查轨迹和时间，形成电子化巡查台账。

**场景4：火灾现场录像取证（P0）**  
某工厂发生真实火灾，消防救援部门需要调取火灾现场录像。系统自动标记火灾发生前后30分钟的录像片段，生成取证包供公安和消防部门使用。

### 3.2 F6.2 视频统一接入（P0）

#### 3.2.1 功能描述

统一接入联网单位现有的安防视频监控和消防专用视频监控设备，实现视频资源的集中管理和调度。

#### 3.2.2 接入能力要求

| 参数 | 规格要求 | 说明 |
|-----|---------|------|
| 协议支持 | GB/T 28181-2016、RTSP、ONVIF、HLS、WebRTC | 标准视频协议全覆盖 |
| 设备类型 | 网络摄像机、NVR、视频服务器、编码器 | - |
| 单平台接入能力 | ≥10000路 | 支持平滑扩展 |
| 单画面解码能力 | ≥1080P@30fps | - |
| 视频流延迟 | ≤500ms（端到端） | 含网络传输延迟 |

#### 3.2.3 视频分类管理

| 视频类型 | 来源 | 用途 | 管理要求 |
|---------|-----|------|---------|
| 消防专用视频 | 火灾探测器关联摄像头 | 火警复核 | 优先保障带宽 |
| 消控室视频 | 消控室监控 | 值班监督、离岗识别 | 7×24在线 |
| 消防通道视频 | 通道监控 | 通道堵塞检测 | 覆盖主要通道 |
| 安全出口视频 | 出口监控 | 疏散情况监测 | 覆盖关键出口 |
| 重点区域视频 | 仓库、配电房等 | 重点防护 | 可选接入 |
| 安防共享视频 | 安防监控系统 | 安消联动 | 按需共享 |

#### 3.2.4 交互流程

```
[前端设备] → [视频网关] → [流媒体服务] → [视频管理平台]
                    ↓
              [协议转换]
              GB28181/RTSP → 内部流
```

#### 3.2.5 输入输出规范

**输入数据**：
- 设备接入信息（设备IP、端口、用户名、密码、通道数）
- 设备能力描述（分辨率、编码格式、是否支持云台）
- 视频流地址（RTSP URL）

**输出数据**：
- 视频播放地址（HLS/WebSocket）
- 设备在线状态
- 视频质量评估

#### 3.2.6 业务规则

| 规则编号 | 规则描述 | 标准来源 |
|---------|---------|---------|
| BR-F6.2-001 | 视频设备应支持GB/T 28181-2016标准协议接入 | T/GDCAA 016-2025 7.1.2 |
| BR-F6.2-002 | 视频流编码格式优先支持H.264/H.265 | T/CFPA 052-2026 5.4.1 |
| BR-F6.2-003 | 消控室视频必须7×24小时在线，断线超过5分钟告警 | T/GDCAA 016-2025 7.1.3 |
| BR-F6.2-004 | 消防联动视频应在告警发生后10秒内完成画面弹出 | T/CFPA 052-2026 5.4.2 |
| BR-F6.2-005 | 视频设备编码采用20位标准编码：区域(6位)+点位(8位)+通道(4位)+校验(2位) | GA/T 1400 B.2 |

#### 3.2.7 验收标准

**AC-F6.2-001：GB28181设备接入**  
- **验收条件**：支持符合GB/T 28181-2016标准的设备一键接入，自动发现和注册  
- **测试方法**：接入10台不同厂商的GB28181设备，验证注册成功率和视频播放

**AC-F6.2-002：多协议支持**  
- **验收条件**：支持RTSP、ONVIF、HLS等协议设备接入，自动适配协议  
- **测试方法**：分别接入各类型协议设备，验证兼容性

**AC-F6.2-003：视频在线监测**  
- **验收条件**：实时展示视频设备在线状态，断线超过5分钟自动告警  
- **测试方法**：断开测试设备网络，观察告警触发时间

### 3.3 F6.3 安消联动（P0）

#### 3.3.1 功能描述

实现消防告警与视频监控的智能联动，告警发生时自动关联最近的3-5个摄像头并弹出视频画面，支持AI辅助分析。

#### 3.3.2 联动规则配置

| 告警类型 | 关联摄像头数量 | 关联优先级 | 辅助分析 |
|---------|--------------|-----------|---------|
| 火警 | 3-5个 | 最近区域→出入口→周边 | 火焰/烟雾识别 |
| 故障 | 1-2个 | 故障设备周边 | - |
| 监管 | 2-3个 | 监管区域摄像头 | 人员入侵检测 |
| 预警 | 1-2个 | 预警区域摄像头 | 异常行为检测 |
| 手动核警 | 按需指定 | 指定摄像头 | - |

#### 3.3.3 联动触发条件

| 条件类型 | 触发规则 | 说明 |
|---------|---------|------|
| 自动触发 | 火警/监管告警 | 系统自动执行联动 |
| 半自动触发 | 故障告警 | 值守员确认后联动 |
| 手动触发 | 任意场景 | 值守员主动发起 |

#### 3.3.4 AI辅助分析能力

| 分析类型 | 适用场景 | 输出内容 |
|---------|---------|---------|
| 火焰识别 | 火警复核 | 置信度、有无火焰、火焰位置 |
| 烟雾识别 | 火警复核 | 置信度、烟雾浓度估算 |
| 人员统计 | 疏散监测 | 区域内人数、密度 |
| 通道状态 | 通道堵塞复核 | 畅通/轻度堵塞/严重堵塞 |

#### 3.3.5 交互流程

```
[消防告警] → [告警解析] → [摄像头定位] → [关联规则匹配]
                                          ↓
                              [视频流拉取] → [AI分析]
                                          ↓
                              [画面弹出+标注] → [值守员复核]
                                          ↓
                                    [复核结果记录]
```

#### 3.3.6 输入输出规范

**输入数据**：
- 告警信息（告警编号、类型、单位、位置、发生时间）
- 摄像头配置（摄像头ID、位置、覆盖区域坐标）
- AI模型配置（模型版本、分析参数）

**输出数据**：
- 关联摄像头列表（含视频流地址）
- AI分析结果（识别标签、置信度、标注坐标）
- 告警复核表单

#### 3.3.7 业务规则

| 规则编号 | 规则描述 | 标准来源 |
|---------|---------|---------|
| BR-F6.3-001 | 火警告警必须自动关联至少3个摄像头，画面弹出延迟≤10秒 | T/CFPA 052-2026 5.4.2 |
| BR-F6.3-002 | 摄像头关联优先级：同区域→同建筑→同单位→邻近单位 | T/CFPA 052-2026 5.4.2 |
| BR-F6.3-003 | AI火焰识别准确率应≥90%，误报率应≤5% | T/GDCAA 016-2025 6.3.5 |
| BR-F6.3-004 | 联动视频应支持画面截图保存，截图包含时间戳和告警编号 | T/GDCAA 016-2025 8.2.3 |
| BR-F6.3-005 | 支持按单位、建筑、楼层配置联动规则模板 | T/CFPA 052-2026 5.4.3 |

#### 3.3.8 验收标准

**AC-F6.3-001：火警联动弹出**  
- **验收条件**：火警告警发生后10秒内完成视频画面弹出，支持多画面分屏展示  
- **测试方法**：模拟推送10条火警，测量告警到视频弹出的平均时间

**AC-F6.3-002：AI辅助分析**  
- **验收条件**：视频弹出时同步展示AI分析结果，支持开启/关闭AI分析  
- **测试方法**：在不同场景下测试火焰/烟雾识别准确性

**AC-F6.3-003：联动规则配置**  
- **验收条件**：支持按单位、告警类型自定义联动规则，规则生效时间≤1分钟  
- **测试方法**：修改联动规则配置，验证生效情况

### 3.4 F6.4 视频复核（P0）

#### 3.4.1 功能描述

提供视频复核工作台，支持值守员对消防告警进行远程核警，判断告警真伪并记录复核结果。

#### 3.4.2 复核工作台功能

| 功能模块 | 功能描述 |
|---------|---------|
| 告警列表 | 展示待复核告警，按时间/级别排序 |
| 视频播放器 | 支持实时视频/录像回放，倍速播放 |
| AI标注层 | 在视频画面上叠加AI识别结果 |
| 截图工具 | 支持快捷键截图，自动保存 |
| 复核表单 | 填写复核结论、备注信息 |
| 快捷操作 | 误报确认、真实火警上报、工单派发 |

#### 3.4.3 复核流程

```
[接收告警] → [查看关联视频] → [AI分析参考] → [人工复核]
                                              ↓
                                    ┌─────────┴─────────┐
                                    ↓                   ↓
                              [误报确认]           [真实火警]
                                    ↓                   ↓
                              [记录归档]         [启动应急预案]
                                                          ↓
                                                    [通知119]
```

#### 3.4.4 复核时效要求

| 告警级别 | 复核时限 | 超时处理 |
|---------|---------|---------|
| 紧急（火警） | 2分钟内 | 自动升级通知负责人 |
| 严重（监管） | 5分钟内 | 短信提醒值守员 |
| 一般（故障） | 30分钟内 | 纳入绩效考核 |

#### 3.4.5 业务规则

| 规则编号 | 规则描述 | 标准来源 |
|---------|---------|---------|
| BR-F6.4-001 | 火警复核必须留有视频证据，录像保留≥5年 | T/GDCAA 016-2025 8.2.2 |
| BR-F6.4-002 | 复核结果分为：真实火警、误报、设备故障、无法确认 | T/CFPA 052-2026 5.4.4 |
| BR-F6.4-003 | 复核记录需包含复核人、时间、复核依据、复核结论 | T/GDCAA 016-2025 8.2.4 |
| BR-F6.4-004 | 真实火警需在复核后1分钟内通知相关责任人 | T/CFPA 052-2026 5.4.4 |
| BR-F6.4-005 | 复核操作应记录完整操作日志，支持审计追溯 | T/GDCAA 016-2025 8.2.4 |

#### 3.4.6 验收标准

**AC-F6.4-001：复核工作台完整性**  
- **验收条件**：支持告警列表、视频播放、AI标注、截图、复核表单完整功能  
- **测试方法**：完整操作一遍复核流程，验证各功能可用性

**AC-F6.4-002：复核时效监控**  
- **验收条件**：系统实时显示复核倒计时，超时自动升级通知  
- **测试方法**：模拟告警等待复核，观察超时升级机制

**AC-F6.4-003：复核记录追溯**  
- **验收条件**：任何复核记录可查询、可追溯，包含完整操作轨迹  
- **测试方法**：查询历史复核记录，验证信息完整性

### 3.6 F6.6 录像回放（P1）

#### 3.6.3 业务规则

### 3.7 F6.7 录像留存（P0）

#### 3.7.1 功能描述

按照分级分类标准留存视频录像，确保火警相关录像长期保存，满足消防安全追溯和取证需求。

#### 3.7.2 留存分级标准

依据T/GDCAA 016-2025第8.2.2条规定：

| 录像类型 | 留存期限 | 说明 | 存储优先级 |
|---------|---------|------|-----------|
| 火警相关 | ≥5年 | 火警告警前后30分钟录像 | 最高 |
| 故障相关 | ≥1年 | 设备故障告警前后15分钟 | 高 |
| 预警相关 | ≥1年 | 风险预警关联录像 | 高 |
| 日常巡查 | ≥3个月 | 消防巡查过程录像 | 中 |
| 常规录像 | ≥30天 | 日常监控录像 | 普通 |

#### 3.7.3 录像标记规则

| 触发条件 | 标记动作 | 录像范围 |
|---------|---------|---------|
| 火警告警 | 锁定+长期留存 | 告警前30分钟~告警后确认 |
| 故障告警 | 标记留存 | 告警前15分钟~告警后1小时 |
| 人工标记 | 按指定时长留存 | 自定义范围 |
| 常规录像 | 自动覆盖 | 按存储容量循环覆盖 |

#### 3.7.4 存储策略

| 存储层级 | 存储介质 | 留存期限 | 说明 |
|---------|---------|---------|------|
| 热存储 | SSD/NVMe | 30天 | 高频访问录像 |
| 温存储 | 企业级HDD | 1年 | 中频访问录像 |
| 冷存储 | 对象存储 | 5年+ | 低频访问录像 |

#### 3.7.5 业务规则

| 规则编号 | 规则描述 | 标准来源 |
|---------|---------|---------|
| BR-F6.7-001 | 火警相关录像必须保留≥5年，到期前不得删除 | T/GDCAA 016-2025 8.2.2 |
| BR-F6.7-002 | 录像存储应支持云端和本地双备份 | T/CFPA 052-2026 5.4.6 |
| BR-F6.7-003 | 录像完整性校验：每周自动校验，确保可正常回放 | T/GDCAA 016-2025 8.2.2 |
| BR-F6.7-004 | 录像删除需经二级审批，记录删除日志 | T/GDCAA 016-2025 8.2.4 |
| BR-F6.7-005 | 录像存储容量计算：1080P@2Mbps≈800MB/小时 | T/CFPA 052-2026 5.4.6 |

#### 3.7.6 验收标准

**AC-F6.7-001：火警录像长期留存**  
- **验收条件**：火警录像5年内可正常回放，支持导出取证  
- **测试方法**：查询历史火警录像，验证完整性和可回放性

**AC-F6.7-002：自动标记功能**  
- **验收条件**：告警发生后自动标记关联录像，无需人工操作

**AC-F6.7-003：存储容量管理**  
- **验收条件**：系统自动计算存储容量，支持容量预警和扩容提醒  
- **测试方法**：模拟存储容量达到阈值，验证预警机制

### 4.2 关键交互设计

1. 告警触发 → 系统自动关联摄像头 → 视频流拉取

1. 选中待复核告警 → 下方展开复核工作区
2. 工作区包含：告警信息卡片、关联视频区、AI分析结果、复核表单

**录像回放交互**：
1. 选择摄像头和时间段 → 显示录像时间轴
2. 时间轴标注告警点（红色）、巡查点（蓝色）
3. 点击标注点可快速定位回放
4. 支持多段录像合并下载
