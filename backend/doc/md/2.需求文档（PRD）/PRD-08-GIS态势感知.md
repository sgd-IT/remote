
# PRD-08 GIS态势感知模块（F8）

**版本**：V1.0  
**制定日期**：2025年  
**标准依据**：T/GDCAA 016-2025  
**优先级**：P1

---

## 1. 模块概述

### 1.1 定位
GIS态势感知模块是智慧消防远程值守系统的可视化中心，基于地理信息系统实现消防设备分布、风险态势、告警定位的直观展示，为消防安全管理人员提供"一图统览"的决策支撑平台。

### 1.2 业务目标
- 实现联网单位及消防设备的空间分布可视化
- 提供基于多维度数据的风险热力图分析
- 实现告警事件的实时定位和快速响应
- 支持区域维度的消防安全态势统计

### 1.3 合规依据

| 标准编号 | 标准名称 | 适用条款 |
|---------|---------|---------|
| T/GDCAA 016-2025 | 智慧消防建设规范 | F8.1-F8.7 |

## 2. 用户角色与场景

### 2.1 用户角色

| 角色 | 职责 | 使用功能 |
|-----|------|---------|
| 消防安全责任人 | 风险态势查看、应急指挥 | F8.1-F8.6 |
| 值班长 | 告警定位查看、应急响应 | F8.3、F8.5、F8.6 |
| 运维工程师 | 设备分布查看、故障定位 | F8.1、F8.2 |
| 系统管理员 | 地图配置、图层管理 | F8.1-F8.7 |
| 消防监管部门 | 数据上报、态势查看 | F8.1-F8.6 |

### 2.2 典型业务场景

**场景1：辖区消防安全态势概览**
- 触发：消防安全责任人登录系统
- 流程：进入GIS态势感知页面 → 查看辖区风险热力图 → 点击风险区域查看详情 → 制定针对性整改措施

**场景2：火警告警快速响应**
- 触发：系统接收到火警告警
- 流程：告警闪烁标注 → 值班员点击标注 → 弹出告警详情卡片 → 快速定位现场位置 → 指挥应急处置

**场景3：设备故障排查**
- 触发：运维工程师需排查设备故障
- 流程：进入设备分布地图 → 按区域/类型筛选 → 定位故障设备 → 查看设备详情 → 派发维保工单

### 3.2 F8.2 风险热力图

#### 3.2.1 功能描述
基于设备运行数据、告警数据、故障数据等多维度信息，计算区域风险指数并以热力图形式展示。

#### 3.2.2 子功能：风险指数计算

**功能描述**：基于多维度数据计算区域风险指数

**风险指数模型**：

| 风险维度 | 权重 | 数据来源 | 计算方式 |
|---------|-----|---------|---------|
| 设备故障率 | 25% | 设备状态数据 | 故障设备数/总设备数 |
| 告警频率 | 25% | 告警记录 | 告警次数/时间周期 |
| 故障响应时长 | 20% | 维保工单数据 | 平均故障修复时长 |
| 设备老化度 | 15% | 设备台账 | 设备使用年限/设计年限 |
| 巡检覆盖率 | 15% | 巡检记录 | 实际巡检/计划巡检 |

**风险等级划分**：

| 风险等级 | 指数范围 | 颜色标识 | 风险描述 |
|---------|---------|---------|---------|
| 高风险 | 70-100 | 红色 | 需要立即整改 |
| 中风险 | 40-69 | 黄色 | 需要关注整改 |
| 低风险 | 0-39 | 绿色 | 运行正常 |

**数据字段**：

| 字段名称 | 数据类型 | 必填 | 字段说明 |
|---------|---------|-----|---------|
| building_id | VARCHAR(32) | 是 | 建筑编号 |
| risk_index | DECIMAL(5,2) | 是 | 风险指数（0-100） |
| device_fault_rate | DECIMAL(5,2) | 是 | 设备故障率 |
| alert_frequency | INT | 是 | 告警频率 |
| avg_repair_time | DECIMAL(10,2) | 是 | 平均修复时长（小时） |
| device_age_rate | DECIMAL(5,2) | 是 | 设备老化度 |
| inspection_rate | DECIMAL(5,2) | 是 | 巡检覆盖率 |
| risk_level | ENUM | 是 | 风险等级 |
| calculate_time | DATETIME | 是 | 计算时间 |
| heat_value | DECIMAL(10,2) | 是 | 热力图权重值 |

**业务规则**：

| 规则编号 | 规则描述 | 标准来源 |
|---------|---------|---------|
| BR-F8.2.001 | 风险指数每日凌晨自动计算更新 | T/GDCAA 016-2025 11.3.1 |
| BR-F8.2.002 | 风险指数范围0-100，等级划分符合规范 | T/GDCAA 016-2025 11.3.2 |
