
# PRD-01 火警监测与处置

> 版本：V1.0 | 日期：2026-06-15 | 模块编号：F1 | 优先级：P0（核心必做）

---

## 1 模块概述

### 1.1 模块定位

火警监测与处置是整个远程值守系统的核心模块，承担从火警信号接收到闭环处置的全流程管理。该模块直接对应GB 25506-2010法定火警处置流程，是远程值守合规性的最关键功能。

### 1.2 业务目标

| 目标 | 指标 | 标准依据 |
|------|------|---------|
| 火警信号不遗漏 | 100%信号接收率 | GB 50440-2007 |
| 火警响应时效 | ≤10s接收、≤30s核实、≤1min通知、≤5min确认结果 | GB/T 26875.1-2026 / T/CFPA 052-2026 / T/GDCAA 016-2025 |
| 处置流程可追溯 | 全流程记录不可篡改 | T/CFPA 052-2026 |
| 误报精准识别 | AI辅助核实准确率≥95% | T/GDCAA 016-2025 |

### 1.3 合规依据

| 标准号 | 条款 | 核心要求 |
|--------|------|---------|
| GB 25506-2010 | 4.3 | 火警处置法定流程 |
| GB 50440-2007 | 4.2 | 信号传输延迟≤30s |
| GB 50116-2013 | 3.1 | 远程监控中心可作为分控端 |
| GB/T 26875.1-2026 | 6.5 | 火警传输延迟≤10s |
| T/CFPA 052-2026 | 4.3 | 火警30s内双重核实 |长度
| T/GDCAA 016-2025 | 7.1 | 1min内通知、5min确认结果 |

## 2 用户角色与场景

### 2.1 角色定义

| 角色 | 操作权限 | 使用终端 | 核心操作 |
|------|---------|---------|---------|
| 远程值守员 | 查看信号、消音复位、记录处置、发起通知 | 值守终端 | 第一响应人 |
| 值守主管 | 含值守员全部权限 + 手自切换、设备启停 | 值守终端 | 高风险操作审批 |
| 技术负责人 | 含主管全部权限 + 系统参数修改 | 管理后台 | 系统级操作 |
| 业主消防安全负责人 | 接收通知、查看报表 | 移动端/Web | 被通知方 |
| 消控室值班员 | 接收通知、现场复核、查岗应答 | 值守屏/移动端 | 现场协同 |
| 监管人员 | 查看记录、抽查数据 | 监管平台 | 监督检查 |

### 2.2 核心场景

**场景1：夜间火警快速处置**

> 凌晨2:15，某商场消防主机报火警。AN-400B在8s内将信号上报平台，值守大屏声光报警+弹窗显示"3层烟感报警"。值守员在20s内完成信号核实+视频复核，视频显示疑似烟雾。值守员一键启动应急预案：远程切换主机至自动模式、拨打119、1min内电话通知消控室值班员和业主负责人。全程记录留痕。

**场景2：误报快速排除**

> 工作日10:30，某办公楼烟感报警。视频复核显示为装修粉尘触发，值守员判定误报，记录误报原因（装修粉尘），远程消音复位，APP通知业主。误报处置全程记录归档。

**场景3：超时自动升级**

> 值守员1min内未响应火警弹窗，系统自动拨打值守主管电话，同时在岗AI识别到值守员离座，触发升级告警。主管远程接管处置。

## 3 功能需求详述

### F1.1 火灾报警信号实时接收

#### 功能描述

接收通过AN-400B上报的火灾报警信号，在值守终端实时展示并触发声光报警。

#### 交互流程

1. AN-400B采集消防主机火警信号，按GB/T 26875.3协议封装上报
2. 数据中台接收并解析信号，完成规则匹配（类型=火警）
3. 值守大屏触发声光报警 + 弹窗显示告警详情
4. 同时推送至值守操作终端 + 移动端
5. 视频联动中心自动弹出关联摄像头画面

#### 输入

| 字段 | 类型 | 必填 | 说明 | 标准依据 |
|------|------|------|------|---------|
| 报警时间 | DateTime | 是 | 消防主机原始报警时间 | GB/T 26875.3 |
| 联网单位编码 | String | 是 | 唯一识别码 | GB/T 26875.1-2026 |
| 建筑名称 | String | 是 | 联网单位名称 | — |
| 报警部位 | String | 是 | 楼层+区域+具体位置 | GB 25506-2010 |
| 设备类型 | Enum | 是 | 烟感/温感/手报/火焰/复合 | GB/T 26875.1附录A |
| 设备地址编码 | String | 是 | 回路号+点位号 | GB/T 26875.1附录A |
| 信号类型 | Enum | 是 | 火警/故障/监管/屏蔽/联动 | GB/T 26875.1附录A |

#### 输出

| 展示终端 | 展示形式 | 内容 |
|---------|---------|------|
| 值守大屏 | 声光+弹窗+地图标注 | 报警单位、位置、设备、时间 |
| 值守操作终端 | 弹窗+闪烁+提示音 | 完整告警详情+操作按钮 |
| 移动端APP | 推送通知 | 简要信息+一键查看详情 |
| 关联摄像头 | 自动弹出实时画面 | 告警位置附近3-5路视频 |

| BR-F1.1-04 | 新火警优先级高于当前处置中的告警 | T/CFPA 052-2026 |
| BR-F1.1-05 | 多点同时报警显示为"群发报警" | — |

#### 验收标准

| AC编号 | 验收条件 | 测试方法 |

### F1.2 信号+视频双重核实

#### 功能描述

值守员在30s内完成信号核实与视频复核，判断火警真伪。

#### 交互流程

1. 火警弹窗显示后，启动30s倒计时
2. 左侧显示报警信号详情（设备/位置/历史告警）
3. 右侧自动弹出关联摄像头实时画面（3-5路）
4. AI引擎同步分析视频，标注检测结果（火焰/烟雾/人员）
5. 值守员根据信号+视频+AI辅助，选择"确认火警"或"确认误报"
6. 30s内未操作，弹窗闪烁加急+倒计时变红

#### 输入

| 字段 | 类型 | 说明 |
|------|------|------|
| 报警信号详情 | Object | F1.1输出的完整告警信息 |
| 关联视频流 | VideoStream[] | 自动匹配的3-5路摄像头画面 |
| AI分析结果 | Object | 火焰概率/烟雾概率/人员计数 |
| 历史告警 | Array | 该设备/位置近30天告警记录 |

#### 输出

| 操作 | 结果 | 后续动作 |
|------|------|---------|
| 确认火警 | 进入火警处置流程(F1.3) | 声光持续+启动应急预案 |
| 确认误报 | 进入误报处置流程(F1.4) | 声光停止+消音复位 |
| 超时未操作 | 触发超时升级(F1.6) | 自动拨打值守主管电话 |

#### 业务规则

| 规则编号 | 规则描述 | 标准依据 |
|---------|---------|---------|
| BR-F1.2-01 | 30s内必须完成双重核实 | T/CFPA 052-2026 4.3 |
| BR-F1.2-02 | 视频复核为强制步骤，不可跳过 | T/CFPA 052-2026 |
| BR-F1.2-03 | AI辅助结果仅供参考，最终由值守员判定 | — |
| BR-F1.2-04 | 关联摄像头自动匹配算法：同楼层>相邻楼层>同建筑 | — |
| BR-F1.2-05 | 无视频接入时，核实步骤降级为电话确认 | — |

#### 验收标准

| AC编号 | 验收条件 | 测试方法 |
|--------|---------|---------|
| AC-F1.2-01 | 火警弹窗后30s倒计时正确显示 | 人工计时验证 |
| AC-F1.2-02 | 关联视频3s内自动弹出 | 计时测试 |
| AC-F1.2-03 | AI分析结果在视频画面上叠加显示 | 功能验证 |
| AC-F1.2-04 | 超时30s后自动升级告警 | 等待超时验证 |
| AC-F1.2-05 | 无视频场景降级为电话确认 | 断开视频模拟测试 |

### F1.3 真实火警处置流程

#### 功能描述

确认真实火警后，按法定流程执行远程操控、报警通知、应急响应等系列操作。

#### 交互流程

```
[确认火警] → 弹出火警处置操作面板
     ↓
步骤1: 远程切换主机至自动模式（值守主管权限）
     → 系统下发GB/T 26875.3控制命令
     → AN-400B转发至消防主机
     → 主机状态确认反馈
     ↓
步骤2: 拨打119报警（一键拨号+自动填充地址信息）
     → 语音网关拨打119
     → 通话录音启动
     → 记录拨打时间
     ↓
步骤3: 通知联网单位消控室（≤1min内）
     → 语音网关自动拨打消控室电话
     → APP推送+短信同步发送
     → 等待接听确认
     ↓
步骤4: 通知业主消防安全负责人
     → APP推送+短信+语音电话
     → 记录通知状态（已读/未读）
     ↓
步骤5: 通知现场人员+微型消防站
     → APP推送+短信
     → 含疏散指引（如有预案）
     ↓
步骤6: 启动应急预案
     → 一键启动预设应急预案
     → 自动执行预设通知列表
     → 预案执行进度实时显示
     ↓
步骤7: 全程记录处置流程
     → 每步操作自动记录时间戳+操作人
     → 视频全程录像
     ↓
步骤8: 5min内确认处理结果
     → 回拨现场确认
     → 更新处置状态
     → 闭环归档
```

#### 输入

| 字段 | 类型 | 说明 |
|------|------|------|
| 火警确认信息 | Object | 包含报警位置、设备、核实结果 |
| 应急预案 | Object | 预设的应急预案配置 |
| 通知列表 | Array | 业主/消控室/微型消防站联系方式 |
| 119报警信息 | Object | 单位地址+建筑信息+报警位置 |

#### 输出

| 产物 | 格式 | 留存时长 | 标准依据 |

| 处置流程记录 | 结构化数据 | ≥3年 | T/CFPA 052-2026 |
| 119通话录音 | 音频文件 | ≥5年 | T/GDCAA 016-2025 |
| 通知记录 | 结构化数据 | ≥3年 | T/CFPA 052-2026 |
| 视频录像 | 视频文件 | 长期保存 | GB/T 26875.1-2026 |
| 应急预案执行记录 | 结构化数据 | ≥3年 | T/CFPA 052-2026 |

#### 业务规则

| 规则编号 | 规则描述 | 标准依据 |
|---------|---------|---------|
| BR-F1.3-01 | 远程切换自动模式需值守主管权限 | GB 25506-2010 |
| BR-F1.3-02 | 1min内必须通知联网单位 | T/GDCAA 016-2025 7.1 |
| BR-F1.3-03 | 5min内必须确认处理结果 | T/GDCAA 016-2025 7.1 |

### F1.4 误报处置流程

#### 功能描述

确认误报后，执行消音复位、记录原因、通知业主等操作。

#### 交互流程

1. 选择"确认误报" → 弹出误报原因选择面板
2. 选择误报原因（预设选项+自定义输入）
3. 远程消音复位（值守员权限即可）
4. APP通知业主（误报确认+原因）
5. 登记误报台账
6. 闭环归档

#### 误报原因分类

| 类别 | 选项 | 说明 |
|------|------|------|
| 环境因素 | 烹饪油烟、装修粉尘、水蒸气、香烟烟雾 | 常见生活场景 |
| 设备因素 | 设备老化、安装位置不当、灵敏度偏高 | 设备本身问题 |
| 作业因素 | 消防演练、设备测试、维修施工 | 有计划的作业 |
| 其他 | 自定义填写 | 预设之外的原因 |

#### 业务规则

| 规则编号 | 规则描述 | 标准依据 |
|---------|---------|---------|
| BR-F1.4-01 | 误报原因必填，不可为空 | GB 25201-2010 |
| BR-F1.4-02 | 消音复位需信号核实后方可执行 | GB 50116-2013 |
| BR-F1.4-03 | 同一设备月累计误报≥3次，自动标记为"高频误报设备" | — |
| BR-F1.4-04 | 高频误报设备自动生成维保建议 | — |
| BR-F1.4-05 | 误报记录不可修改删除 | T/CFPA 052-2026 |

#### 验收标准

| AC编号 | 验收条件 | 测试方法 |
|--------|---------|---------|
| AC-F1.4-01 | 误报原因为必填项 | 不填原因，验证无法提交 |
| AC-F1.4-02 | 消音复位操作正常 | 执行消音复位，验证设备状态变化 |
| AC-F1.4-03 | 业主APP收到误报通知 | 检查APP推送 |
| AC-F1.4-04 | 误报台账记录完整 | 检查台账字段 |
| AC-F1.4-05 | 同设备月误报3次后标记"高频误报" | 模拟3次误报 |

### F1.5 故障信息处置

#### 功能描述

接收并处置消防设施故障信号，通知维保单位，跟踪整改闭环。

#### 交互流程

1. 故障信号接收 → 值守终端提示（声光等级低于火警）
2. 30min内通知联网单位+维保单位（语音/短信/APP）
3. 登记故障台账（设备/时间/现象/通知记录）
4. 全程跟踪整改：
   - 72h内修复 → 闭环销项
   - 超72h → 通知消防安全负责人
   - 超3天 → 上报属地消防部门
5. 修复后验证 → 状态确认+记录
6. 闭环归档

#### 业务规则

| 规则编号 | 规则描述 | 标准依据 |
|---------|---------|---------|
| BR-F1.5-01 | 30min内通知联网单位+维保单位 | T/GDCAA 016-2025 |
| BR-F1.5-02 | 故障信号逐条登记 | GB 25201-2010 5.1 |
| BR-F1.5-03 | 超72h未修复自动升级通知 | — |
| BR-F1.5-04 | 超3天未修复上报消防部门 | — |
| BR-F1.5-05 | 严禁屏蔽故障信号 | GB 25201-2010 5.2 |

#### 验收标准

| AC编号 | 验收条件 | 测试方法 |
|--------|---------|---------|
| AC-F1.5-01 | 故障通知在30min内发出 | 计时测试 |
| AC-F1.5-02 | 故障台账逐条登记完整 | 检查台账字段 |
| AC-F1.5-03 | 超72h升级通知自动触发 | 模拟超时场景 |
| AC-F1.5-04 | 屏蔽操作被系统拒绝 | 尝试屏蔽，验证拒绝 |
| AC-F1.5-05 | 修复后闭环流程正常 | 模拟完整闭环 |

### F1.6 超时升级机制

#### 功能描述

火警信号核实超时或处置超时时，系统自动升级告警，确保不遗漏。

#### 升级规则

| 超时场景 | 超时阈值 | 升级动作 | 标准依据 |
|---------|---------|---------|---------|
