
# PRD-10 移动端模块（F10）

**版本**：V1.0  
**制定日期**：2025年  
**标准依据**：T/CFPA 052-2026、T/GDCAA 016-2025  
**优先级**：P0/P1

---

## 1. 模块概述

### 1.1 定位
移动端模块是智慧消防远程值守系统的移动入口，支持多角色用户在移动终端上完成值守、告警、巡检、工单等业务操作，实现消防安全的移动化、即时化管理。

### 1.2 业务目标
- 实现多角色移动端应用，支持iOS、Android、鸿蒙三端
- 确保告警推送时效性，满足火警1分钟、故障30分钟、预警15分钟要求
- 提供现场取证能力，支持拍照、录像、录音、定位
- 支持离线操作，确保网络中断情况下业务连续性

### 1.3 合规依据

| 标准编号 | 标准名称 | 适用条款 |
|---------|---------|---------|
| T/CFPA 052-2026 | 消防物联网系统运维管理规范 | F10.1-F10.6 |
| T/GDCAA 016-2025 | 智慧消防建设规范 | F10.1-F10.6 |

## 2. 用户角色与场景

### 2.1 用户角色

| 角色 | 职责 | 优先级 | 使用功能 |
|-----|------|-------|---------|
| 值守员 | 移动值守、告警查看 | P1 | F10.1 |
| 业主负责人 | 告警推送、关键指标、报表、应急预案 | P0 | F10.2 |
| 消控室值班员 | 告警接收、查岗应答、现场复核 | P0 | F10.3 |
| 维保工程师 | 工单接收、维保记录 | P1 | F10.4 |
| 运维工程师 | 设备巡检、故障排查 | P1 | F10.5 |

### 2.2 典型业务场景

**场景1：消控室值班员接收火警**
- 触发：系统检测到火警
- 流程：收到推送通知 → 快速查看告警详情 → 确认火警/误报 → 如为真实火警通知相关人员 → 现场复核 → 处置记录

**场景2：维保工程师执行工单**
- 触发：收到维保工单派发
- 流程：收到工单通知 → 接单 → 到达现场签到 → 执行维保 → 拍照记录 → 提交报告 → 业主确认

**场景3：运维工程师移动巡检**
- 触发：到达巡检点位
- 流程：扫码签到 → 执行检查 → 发现异常上报 → 继续巡检 → 完成巡检

## 4. 交互说明

### 4.1 界面设计原则
- 移动端界面简洁清晰，重点突出
- 重要操作一步直达，减少操作层级
- 支持手势操作（滑动、下拉刷新）
- 深色模式适配

### 4.2 关键交互流程

#### 4.2.1 告警处理流程
```
收到推送 → 点击查看详情 → 确认/误报/复核 → 处置完成

#### 4.2.2 维保工单流程
```
收到工单 → 接单 → 到达签到 → 执行维保 → 拍照记录 → 提交报告 → 业主签字
```

#### 4.2.3 巡检执行流程
```
接收任务 → 扫码签到 → 检查点检 → 发现异常上报 → 继续巡检 → 完成签退
```

### 4.3 异常处理
- 网络异常显示离线模式标识
- 操作失败提示重试
- 拍照失败提示摄像头权限
- 定位失败提示GPS权限
