## 1. 模块概述

### 1.1 定位
远程控制模块（F2）是智慧消防远程值守系统的核心功能模块，承担消防控制设备的远程操作与指令下发职能。依据GB 50116-2013火灾自动报警系统设计规范，实现对消火栓泵、喷淋泵、送排风机、消防讯响器等关键设备的远程启停控制，同时通过GB/T 26875.3协议族确保控制命令的标准性与兼容性。

### 1.2 业务目标
| 目标层级 | 具体目标 |
|----------|----------|
| 效率目标 | 减少现场处置响应时间≥60%，实现告警后30秒内完成远程确认 |
| 安全目标 | 零无授权操作、双人复核覆盖率100%、操作留痕可追溯≥5年 |
| 合规目标 | 控制命令100%符合GB/T 26875.3协议、权限验证符合T/GDCAA 016-2025 |
| 质量目标 | 控制指令到达率≥99.9%、执行结果确认率100% |

### 1.3 合规依据

| 标准编号 | 标准名称 | 适用条款 |
|----------|----------|----------|
| GB 50116-2013 | 火灾自动报警系统设计规范 | 第6.3节手动控制功能要求 |
| GB 25506-2010 | 消防控制室通用技术要求 | 第5.5节控制功能要求 |
| T/CFPA 052-2026 | 消防设施操作员远程值守能力评价规范 | 第6.2节远程控制权限要求 |
| T/GDCAA 016-2025 | 建筑消防设施远程控制技术规程 | 全文适用，特别是第7节安全控制要求 |
| GB/T 26875.3-2011 | 城市消防远程监控系统 第3部分 | 报警传输和交换方法 |

## 2. 用户角色与场景

### 2.1 用户角色定义

| 角色 | 岗位 | 系统角色ID | 远程控制权限范围 |
|------|------|------------|------------------|
| 普通用户 | 值守员 | ROLE_WATCHER | 消音、复位、记录 |
| 操作用户 | 值守主管 | ROLE_SUPERVISOR | 手自切换、设备启停、消控操作 |
| 管理用户 | 技术负责人 | ROLE_ADMIN | 系统参数、权限配置、后台管理 |

### 2.2 典型业务场景

#### 场景一：误报火警远程复位
- **触发条件**：值守员收到误报火警，确认现场无异常
- **操作路径**：查看告警详情 → 消音 → 复位
- **权限要求**：普通权限
- **标准依据**：GB 25506-2010 第5.5.2条

#### 场景二：消防泵远程启动
- **触发条件**：火灾确认，需要远程启动消火栓泵
- **操作路径**：收到火灾报警 → 确认火灾 → 申请授权 → 双人复核 → 下发控制命令
- **权限要求**：操作权限 + 业主授权 + 双人复核
- **标准依据**：T/CFPA 052-2026 第6.2.3条

#### 场景三：系统参数远程调整
- **触发条件**：根据消防法规要求调整系统阈值
- **操作路径**：管理入口 → 参数配置 → 双人复核 → 保存生效
- **权限要求**：管理权限 + 双人复核
- **标准依据**：T/GDCAA 016-2025 第7.4条

## 3. 功能需求详述

### 3.1 F2.1 控制功能清单

#### F2.1.1 消音功能（普通权限）

| 属性 | 内容 |
|------|------|
| **功能描述** | 对当前报警主机发出的声音报警信号进行消音处理 |
| **交互流程** | 1. 值守员点击「消音」按钮 → 2. 系统显示消音确认对话框 → 3. 值守员确认消音 → 4. 系统下发消音命令 → 5. 显示消音结果 |
| **输入** | 消音指令（设备ID、操作员ID、时间戳） |
| **输出** | 消音状态更新、操作用户日志记录 |
| **业务规则** | - 消音仅屏蔽声音，不清除报警状态<br>- 消音后新报警自动恢复声音<br>- 消音记录需保存备查 |
| **验收标准** | AC-F2.1.1-01：点击消音按钮后，报警主机在5秒内停止声响<br>AC-F2.1.1-02：消音操作生成不可删除的操作日志<br>AC-F2.1.1-03：新报警触发时声音自动恢复 |
| **标准依据** | GB 25506-2010 第5.5.2条；T/GDCAA 016-2025 第5.2条 |

#### F2.1.2 复位功能（普通权限）

| 属性 | 内容 |
|------|------|
| **功能描述** | 复位火灾报警系统，清除已恢复正常的报警状态 |
| **交互流程** | 1. 值守员确认现场无火情 → 2. 点击「复位」按钮 → 3. 系统验证权限 → 4. 下发复位命令 → 5. 显示复位结果 → 6. 记录操作日志 |
| **输入** | 复位指令（设备ID、操作员ID、复位原因、确认状态） |
| **输出** | 系统复位状态、操作日志记录 |
| **业务规则** | - 复位前必须确认现场已排查<br>- 复位仅清除已恢复正常的报警<br>- 持续报警状态不可复位<br>- 复位失败需记录原因 |
| **验收标准** | AC-F2.1.2-01：复位命令执行后，系统恢复正常监视状态≤10秒<br>AC-F2.1.2-02：未恢复的报警点位不可通过复位清除<br>AC-F2.1.2-03：每次复位操作生成带时间戳的审计日志 |
| **标准依据** | GB 50116-2013 第6.3.1条；T/CFPA 052-2026 第6.2.1条 |

| 属性 | 内容 |
|------|------|
| **功能描述** | 切换消防联动控制器的控制方式（手动/自动） |

### 3.2 F2.2 控制安全机制

#### F2.2.1 授权验证

| 属性 | 内容 |
|------|------|
| **功能描述** | 对控制操作进行多因素身份验证 |
| **交互流程** | 1. 操作人员发起控制请求 → 2. 系统验证账号密码 → 3. 要求输入动态验证码 → 4. 高风险操作要求短信/声纹二次确认 → 5. 验证通过允许操作 |
| **输入** | 操作人员凭证（账号、密码、动态口令、授权码） |
| **输出** | 验证结果、可执行操作列表 |
| **业务规则** | - 密码复杂度符合等保要求（8位以上，含大小写字母、数字、特殊字符）<br>- 动态验证码有效期60秒<br>- 连续5次验证失败账号锁定30分钟<br>- 授权码由业主授权人实时提供 |
| **验收标准** | AC-F2.2.1-01：身份验证失败操作不被执行<br>AC-F2.2.1-02：验证过程日志完整记录<br>AC-F2.2.1-03：账号锁定机制正常生效<br>AC-F2.2.1-04：授权码一次性使用，不可重用 |
| **标准依据** | T/GDCAA 016-2025 第7.1条；GB 25201-2010 第6.2条 |

#### F2.2.2 双人复核机制

| 属性 | 内容 |
|------|------|
| **功能描述** | 高风险控制操作需两名授权人员分别操作和确认 |
| **交互流程** | 1. 操作员发起高风险请求 → 2. 系统生成复核任务 → 3. 复核员登录确认身份 → 4. 复核员验证操作内容 → 5. 复核员输入复核密码 → 6. 复核通过执行操作 → 7. 记录双人信息 |
| **输入** | 操作请求、复核确认（复核员ID、复核密码、时间戳） |
| **输出** | 复核结果、操作执行状态 |
| **业务规则** | - 操作员与复核员不可为同一人<br>- 复核有效期5分钟，超时需重新发起<br>- 复核拒绝需记录拒绝原因<br>- 复核过程全程记录 |
| **验收标准** | AC-F2.2.2-01：复核超时自动取消操作请求<br>AC-F2.2.2-02：单人无法完成高风险操作<br>AC-F2.2.2-03：复核拒绝记录包含拒绝原因<br>AC-F2.2.2-04：复核有效期可配置（默认5分钟） |
| **标准依据** | T/CFPA 052-2026 第6.2.5条；T/GDCAA 016-2025 第7.2条 |

#### F2.2.3 通讯保持

| 属性 | 内容 |
|------|------|
| **功能描述** | 关键控制命令执行过程中保持实时通讯连接 |

#### F2.2.4 操作留痕（不可删改）

| 属性 | 内容 |
|------|------|
| **功能描述** | 所有控制操作生成不可篡改的审计日志 |
| **交互流程** | 系统自动记录 → 加密存储 → 时间戳固化 → 日志写入 → 归档管理 |
| **输入** | 操作事件（操作人、操作类型、操作对象、操作时间、操作结果） |

| **验收标准** | AC-F2.2.4-01：日志哈希值可验证未被篡改<br>AC-F2.2.4-02：日志查询响应时间≤3秒（100万条记录内）<br>AC-F2.2.4-03：日志导出格式PDF不可篡改<br>AC-F2.2.4-04：日志存储容量可扩展≥1000万条 |

#### F2.2.5 关闭确认
