## F1 告警处置模块（核心，P0）

### F1.1 火灾报警处置

**标准依据**：GB 25506-2010、T/CFPA 052-2026、T/GDCAA 016-2025

#### 处置流程

```
信号接收(≤10s) → 声光报警+弹窗 → 30s内双重核实(信号+视频)
  │
  ├─ 确认真实火警 ─────────────────────────────────────┐
  │  1. 远程切换主机至自动模式                          │
  │  2. 拨打119报警                                    │
  │  3. 电话通知联网单位消控室(1min内)                   │
  │  4. 通知业主消防安全负责人                          │
  │  5. 通知现场人员+微型消防站                         │
  │  6. 启动应急预案                                   │
  │  7. 全程记录处置流程                               │
  │  8. 5min内确认处理结果                              │
  │                                                    │
  ├─ 确认误报 ─────────────────────────────────────────┤
  │  1. 记录误报原因                                   │
  │  2. 远程消音复位                                   │
  │  3. 通知联网单位                                   │
  │  4. 登记台账                                       │
  │                                                    │
  └─ 1min内未响应 ─────────────────────────────────────┤
     立即人工电话通知值班人或消防安全负责人               │
```

#### 功能清单

| 子功能 | 说明 | 标准依据 |
|--------|------|---------|
| 告警信号实时接收 | ≤10s内接收火警信号，声光+弹窗+语音提示 | GB/T 26875.1-2026 |
| 信号+视频双重核实 | 30s内完成信号确认+关联视频复核 | T/CFPA 052-2026 |
| 一键启动应急预案 | 自动执行预设应急流程 | T/GDCAA 016-2025 |
| 多渠道通知 | 1min内电话/语音/短信/APP通知联网单位 | T/GDCAA 016-2025 |
| 超时升级 | 1min未响应→人工电话通知 | T/GDCAA 016-2025 |
| 处置全流程记录 | 接收→核实→处置→通知→结果，完整留存 | GB 25506-2010 |
| 远程切换自动模式 | 确认火警后一键切换主机至自动 | GB 25506-2010 |

### F1.2 故障信息处置

**标准依据**：GB 25201-2010、T/GDCAA 016-2025

```
故障信号接收 → 30min内通知联网单位+维保单位
  → 登记故障台账
  → 全程跟踪整改
    → 72h内修复 → 闭环销项
    → 超72h → 通知消防安全负责人
    → 超3天 → 上报属地消防部门
  → 修复后验证 → 闭环
```

  → 处置结果录入
