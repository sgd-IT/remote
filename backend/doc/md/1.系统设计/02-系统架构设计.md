
# 智慧消防远程值守系统 — 系统架构设计

> 版本：V1.0 | 日期：2026-06-14 | 依据：GB 50440-2007、GB/T 26875.1-2026、T/CFPA 052-2026、T/GDCAA 016-2025

---

## 一、架构设计原则

| 原则 | 来源 | 设计要求 |
|------|------|---------|
| 实用性 | GB/T 26875.1-2026 | "技防+人防相结合"，满足消防安全管理实际需求 |
| 拓展性 | GB/T 26875.1-2026 | 层次化、模块化设计，支持规模拓展/功能拓展/软件升级 |
| 易操作性 | GB/T 26875.1-2026 | 清晰简洁的人机交互界面，中文显示 |
| 安全性 | GB/T 26875.1-2026 | 防非法接入/攻击/篡改/病毒，敏感数据加密存储和传输 |
| 可维护性 | GB/T 26875.1-2026 | 设备/用户/参数便于管理和配置 |
| 稳定性 | GB/T 26875.1-2026 | 容错能力强，数据有备份或冗余措施 |

## 三、各层详细设计

### 3.1 感知层

**标准依据**：GB/T 26875.1-2026附录A、GB 50116-2013

#### 3.1.1 数据采集范围（15类消防设施，GB/T 26875.1-2026附录A强制）

| 类别 | 采集信号 | 采集方式 | 传输装置 |
|------|---------|---------|---------|
| 1. 火灾自动报警系统 | 火警/故障/监管/屏蔽/联动信号 | 消防主机CAN/RS232/RS485 | AN-400B采集控制器 |
| 2. 消防给水及消火栓系统 | 水泵状态/管网压力/水池液位 | 一体式水压/液位传感器 | 物联网传感器 |
| 3. 自动喷水灭火系统 | 报警阀/水流指示器/压力开关 | 主机联动信号 | AN-400B |
| 4. 气体灭火系统 | 喷洒/故障/手自动状态 | 主机联动信号 | AN-400B |
| 5. 泡沫灭火系统 | 泵组/比例混合器/阀门状态 | 主机联动信号 | AN-400B |
| 6. 干粉灭火系统 | 状态信号 | 主机联动信号 | AN-400B |
| 7. 防烟排烟系统 | 风机状态/阀门状态 | 主机联动信号 | AN-400B |
| 8. 防火门及防火卷帘 | 开闭状态/故障 | 防火门监控器 | AN-400B |
| 9. 消防电梯 | 迫降/故障状态 | 主机联动信号 | AN-400B |
| 10. 消防应急广播 | 启动/故障状态 | 主机联动信号 | AN-400B |
| 11. 消防电话 | 通话状态 | 主机联动信号 | AN-400B |
| 12. 消防应急照明和疏散指示 | 主电/备电/故障 | 应急照明控制器 | AN-400B |
| 13. 消防电源 | 主备电/电压/电流 | 消防电源监控器 | AN-400B |
| 14. 独立式探测报警器 | 报警/故障/电量 | NB-IoT/4G | 物联网传感器 |
| 15. 传输装置自身 | 在线/离线/故障/通信状态 | 自检上报 | 自身 |

#### 3.1.2 采集控制器（AN-400B）技术规格

| 参数 | 规格 | 标准依据 |
|------|------|---------|
| 接口 | CAN + RS232 + RS485 | GB 50116-2013 |
| 协议 | GB/T 26875.3-2011 | GB/T 26875.3 |
| 采集频率 | 实时，信号变化即时上报 | GB 50440-2007 |
| 传输延迟 | ≤10s | GB/T 26875.1-2026 |
| 断线缓存 | 本地缓存+断网续传 | GB 50440-2007 |
| 授时 | 平台统一授时，偏差≤5s | GB/T 26875.1-2026 |
| 电源 | 220V AC + 内置UPS | GB 50440-2007 |
| 安装方式 | 壁挂/机柜，不改动原有消防系统 | 安为方案差异化 |

### 3.2 传输层

**标准依据**：GB/T 26875.3-2011、T/GDCAA 016-2025

#### 3.2.1 通信协议架构

```
┌─────────────────────────────────────────┐
│          应用层协议                      │
│   GB/T 26875.3 消防专用通信协议          │
│   (命令字节: 控制命令/发送数据/确认/     │
│    请求/应答/否认)                       │
├─────────────────────────────────────────┤
│          传输层                          │
│   TCP/IP (主) / UDP/IP (辅)             │
├─────────────────────────────────────────┤
│          网络层                          │
│   4G/5G / 有线宽带 / NB-IoT             │
└─────────────────────────────────────────┘
```

#### 3.2.2 数据包结构（GB/T 26875.3-2011）

| 字段 | 长度 | 说明 |
|------|------|------|
| 启动符 | 2B | 固定0x4040 |
| 流水号 | 2B | 递增序号 |
| 版本号 | 2B | 主版本1 + 用户版本 |
| 时间标签 | 6B | 年月日时分秒 |
| 源地址 | 6B | 发送方地址 |
| 目的地址 | 6B | 接收方地址 |
| APDU长度 | 2B | ≤1024 |
| 命令字节 | 1B | 控制命令/数据/确认/请求/应答/否认 |
| 应用数据 | ≤1024B | 类型标志+对象数+信息对象 |
| 校验和 | 1B | 算术校验和 |
| 结束符 | 2B | 固定0x2323 |

#### 3.2.3 重发机制

| 参数 | 值 |
|------|-----|
| 超时时间 | ≤10s |
| 重发次数 | 3次 |
| 校验错误类型 | 校验和错误/不可识别命令/APDU超限/启动结束符错误 |

#### 3.2.4 通信安全

| 要求 | 实现方式 | 标准依据 |
|------|---------|---------|
| 数据加密传输 | HTTPS/TLS | T/GDCAA 016-2025 |
| 内外网隔离 | 网络隔离+数据交换区 | T/GDCAA 016-2025 |
| 等级保护 | ≥二级 | T/GDCAA 016-2025 |
| 数据完整性 | 校验和+数字签名 | GB/T 26875.3 |

## 五、数据流设计

### 5.1 火警信号数据流

```
[消防主机] 火警信号
     ↓ (CAN/RS232/RS485)
[AN-400B采集控制器] 协议转换+封装
     ↓ (GB/T 26875.3, TCP/IP)
[数据中台] 接收+解析+规则匹配
     ↓ (≤10s)
[消息推送] 多渠道分发
     ├→ [值守大屏] 声光+弹窗+定位
     ├→ [值守终端] 处置操作台
     ├→ [视频联动] 自动弹出关联视频
     ├→ [语音网关] 1min内电话通知联网单位
     ├→ [APP推送] 通知业主/现场人员
     └→ [操作日志] 记录信号接收时间
```

### 5.2 远程控制数据流

```
[值守员] 发起控制请求
     ↓
[权限验证] 三级权限+授权检查
     ↓
[双人复核] (高风险操作)
     ↓
[远程控制网关] 命令封装
     ↓ (GB/T 26875.3, 控制命令)
[AN-400B] 协议转换+下发
     ↓
[消防主机] 执行控制
     ↓
```
