## 三、核心业务场景

### 场景1：火警处置（最高优先级，法定流程）

```
消防主机火警信号 → 传输装置上报 → 监控中心接收(≤10s)
  → 声光报警+弹窗+语音 → 值守员30s内双重核实(信号+视频)
    → 确认真实火警:
      → 远程切换主机至自动模式
      → 拨打119
      → 通知业主负责人+现场人员+微型消防站
      → 全程记录处置流程
    → 确认误报:
      → 记录误报原因
      → 远程消音复位
      → 通知业主
```

**标准依据**：GB 25506-2010法定流程、T/CFPA 052-2026第6.3条、T/GDCAA 016-2025

### 场景2：故障处置

```
设备故障信号 → 监控中心接收 → 10min内通知业主+维保单位
  → 登记故障台账 → 全程跟踪整改
    → 72h内修复 → 闭环销项
    → 超72h → 通知消防安全负责人
    → 超3天 → 上报属地消防部门
```

### 场景3：远程操控（需授权）

```
告警发生 → 判断需远程控制 → 检查授权状态
  → 已授权: 执行控制(消音/复位/手自切换/启停设备)
  → 未授权: 请求授权 → 获批后执行
  → 全程: 双人复核(高风险) + 操作日志留痕
```

### 场景4：日常巡检与查岗

```
定时/随机查岗 → 推送查岗指令 → 联网单位应答
  → 应答成功: 记录存档
  → 超时未答: 自动升级通知 → 记录脱岗
```

### 场景5：维保管理

```
故障/定期维保 → 生成维保工单 → 派发给维保单位
  → 维保执行(定位+照片+记录) → 提交报告
  → 业主评价 → 闭环
```
