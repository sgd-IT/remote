## 一、项目概述

### 1.1 项目目标

建设一套符合 **GB 50440-2007、GB/T 26875.1-2026、T/CFPA 052-2026、T/GDCAA 016-2025** 等标准的智慧消防远程值守系统，实现：

- **7×24小时** 远程值守，支持多联网单位集中监控
- **10秒内** 火警信号接收，1分钟内核实确认
- **双人复核** 机制确保远程控制合规安全
- **数据不可篡改** 满足消防法规要求
- 多端协同：Web端值守大屏 + 联网单位端 + 移动APP

### 1.2 团队配置

## 二、技术架构与选型

### 2.1 技术栈总览

| 层级 | 技术选型 | 选型理由 |
|------|---------|---------|
| **前端框架** | Vue 3 + Element Plus | 组件丰富、中文文档完善、适合企业级后台 |
| **移动端** | uni-app (Vue3) | 跨平台(iOS/Android/HarmonyOS)、一套代码多端运行 |
| **后端框架** | Java Spring Boot 3 | 成熟稳定、社区生态完善、适合高并发场景 |
| **API风格** | RESTful + WebSocket | REST规范接口 + 实时告警推送 |
| **关系数据库** | MySQL 8.0 | 成熟稳定、主从复制成熟、成本低 |
| **时序数据库** | InfluxDB | 专为IoT时序数据优化、压缩率高、查询快 |
| **缓存** | Redis Cluster | 高性能缓存、Session共享、实时数据缓存 |
| **消息队列** | Kafka | 高吞吐、持久化、实时告警流处理 |
| **视频流媒体** | LiveGBS (GB28181) + EasyDarwin | 国标GB28181协议支持、RTSP流转FLV |
| **AI分析** | Python FastAPI + TensorFlow/PyTorch | AI模型灵活部署、推理性能优异 |
| **地图服务** | 高德地图 JavaScript API | 免费额度高、定位准确、本地化好 |
| **文件存储** | MinIO (S3兼容) | 私有化部署、视频/图片存储 |
| **容器化** | Docker + Kubernetes | 弹性伸缩、服务编排、灰度发布 |
| **CI/CD** | GitLab CI + ArgoCD | 代码托管、自动化部署、GitOps |

### 2.3 消防协议接入

| 接入方式 | 协议 | 说明 |
|---------|------|------|
| 采集控制器 | GB/T 26875.3 | AN-400B通过TCP/IP接入 |
| 消防主机直连 | Modbus/私有协议 | 适配主流消防主机品牌 |
| 物联网传感器 | MQTT | NB-IoT/4G传感器数据上报 |
| 视频设备 | GB/T 28181 / RTSP | 安防/消防摄像头统一接入 |
